## 1. FAQ 추가 항목 초안 (복사용)

```
## 공유 폴더
- Q7. 공유 폴더는 어떤 기능인가요? → 폴더 단위로 노트를 팀원과 함께 보는 기능입니다. 링크 하나로 초대하고, 보기 전용 또는 편집 가능 권한을 고를 수 있습니다.
- Q8. 이미 공유한 폴더의 권한을 바꿀 수 있나요? (보기 → 편집) → [확인 필요: 변경 가능 여부와 메뉴 경로]
- Q9. 팀원이 공유 폴더의 노트를 수정하지 못해요 → 편집 가능 권한으로 공유되어야 수정할 수 있습니다. 보기 전용으로 공유하셨다면 [확인 필요: Q8 절차 확정 후 연결]
- Q10. 누가 노트를 고쳤는지 알 수 있나요? → 네. 공유 폴더에서는 누가 언제 수정했는지 변경 기록을 확인할 수 있습니다. [확인 필요: 변경 기록을 여는 위치]
- Q11. 공유 폴더는 몇 개, 몇 명까지 쓸 수 있나요? → 무료 플랜은 공유 폴더 1개, 멤버 3명까지입니다. 프로 플랜(월 6,900원)은 무제한입니다.
```

### 일부러 넣지 않은 것
- **출시일**: 제품 소개에는 "2026-11-25"로 적혀 있지만 회의록은 "잠정, QA 결과 보고 최종 확정"입니다. 확정 전에는 FAQ에 날짜를 넣지 않습니다. 넣어야 한다면 오너 확정 후 한 줄 추가.
- **Q8 절차 추측** (예: "폴더 우클릭 > 공유 > 권한 변경"): Q1 경로를 보고 그럴듯하게 만들 수 있지만 근거가 없어 쓰지 않았습니다.
- **링크를 다시 만들어 공유하는 우회 방법**: 기존 링크·멤버에 어떤 영향이 있는지 자료가 없어 넣지 않았습니다.
- **Android 3.2.1 크래시 안내**: 버그 대응 내용이 정해지지 않아 FAQ에 넣지 않았습니다(기존 Q6 버그 신고 안내로 충분).

## 2. Q8을 채우려면 확인할 것 (개발 담당 이도윤 님 또는 오너)
| # | 질문 |
|---|---|
| 1 | 이미 공유한 폴더의 권한을 나중에 바꿀 수 있나요? (보기 ↔ 편집) |
| 2 | 바꿀 수 있다면 메뉴 경로는? (데스크톱 / Android / iOS가 같은지) |
| 3 | 권한은 링크 단위인가요, 멤버 단위인가요? (멤버별로 다르게 줄 수 있는지) |
| 4 | 바꾸면 이미 들어온 멤버에게 바로 적용되나요, 다시 초대해야 하나요? |
| 5 | 권한을 바꿀 수 있는 사람은 폴더를 만든 사람뿐인가요? |
| 6 | 변경 기록(Q10)은 어디서 여나요? |

> 참고: 기존 FAQ Q1에 공유 폴더 만드는 법이 이미 있는데, 공유 폴더는 아직 출시 전 신규 기능입니다. 고객 메일 1·3에서도 이미 사용 중인 것으로 보입니다(베타 등). FAQ 게시 시점을 출시에 맞출지 오너 판단이 필요합니다.

## 3. 메일 1(정민지 님) 답장 초안 수정 제안 — 제안만, 발송 안 함
- 현재 초안(`results/01_client_inbox.md`)은 Q1·Q9 앞 문장과 내용이 같고, 권한 변경은 "담당자 확인 후 안내"로 남겨 두어 **지금 그대로 써도 FAQ와 어긋나지 않습니다.**
- 제안 A (Q8 확정 후): "이미 공유하신 폴더의 권한을 바꾸는 방법은 담당자 확인 후 안내드리겠습니다." 문장을 확정된 Q8 절차로 바꿉니다.
- 제안 B (지금 바로 가능, 선택): 고객 상황 확인을 위해 한 줄 추가.
  > 혹시 처음 공유하실 때 **보기** 권한을 선택하셨는지 확인해 주시면, 그에 맞춰 안내드리겠습니다.
- 넣지 말 것: 출시일, 권한 변경 절차 추측, 해결 시점 약속.
- 표시: **사람 검토 필요** (Q8 미확정)
