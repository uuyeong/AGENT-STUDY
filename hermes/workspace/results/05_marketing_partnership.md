## 2. 검토 의견
**긍정 요소**
- 공유 폴더의 주요 사용자 중 하나가 “소규모 스터디 모임”(제품 소개서). 대학생 스터디는 이 타깃과 겹칠 수 있다.
- 무료 플랜(공유 폴더 1개, 멤버 3명)이 있어, 비용 부담 없이 써보게 하는 형태의 홍보는 구성할 수 있다. 단, 할인·쿠폰 등 혜택은 **정책에 없으므로** 제안하거나 약속하지 않는다.

**우려 요소**
| 우려 | 내용 | 대응 |
|---|---|---|
| 신원 불명 | 회사명이 일반 명사형이고 메일 본문 한 줄뿐. 사업자 정보·홈페이지 없음 | 신원 확인 후 진행 (아래 3번) |
| 비용 구조 불명 | 광고비·수수료를 요구하는 영업 메일일 수 있음 | 비용 유무를 첫 질문으로 확인 |
| 개인정보 | 공동 프로모션에서 회원 정보 공유·수집 요구가 나올 수 있음 | 고객 정보 제공은 하지 않는 것을 기본 원칙으로 [오너 확인 필요] |
| 일정 충돌 | 개발 11/20 → QA 약 11/22 → 출시 11/25(잠정), 크래시 버그 담당 미정 | 출시·버그 안정 후로 프로모션 시점 미루기 |
| 담당자 없음 | 칸반상 “제휴 결정” 담당 미정 | 오너가 담당 지정 |

## 3. 상대 신원 확인 — **필요함**
메일만으로는 실제 회사인지 알 수 없습니다. 미팅 전에 아래를 확인할 것을 권장합니다.
| 확인 항목 | 방법 |
|---|---|
| 정식 회사명·사업자등록번호 | 회신으로 요청 → 국세청 사업자 상태 조회로 대조 |
| 회사 홈페이지·운영 커뮤니티 주소 | 회신으로 요청 → 실제 운영 여부 직접 확인 |
| 회사 도메인 메일 사용 여부 | 회신 받은 주소가 회사 도메인인지 확인 |
| 담당자 이름·직책 | 회신으로 요청 |
| 과거 제휴 사례 | 회신으로 요청 → 공개 자료로 확인 가능하면 대조 |

## 4. 상대에게 물어볼 질문 목록
**A. 회사·커뮤니티**
1. 정식 회사명, 사업자등록번호, 홈페이지 주소를 알려주실 수 있나요?
2. 운영하시는 커뮤니티 이름과 주소는 무엇인가요?
3. 회원 수, 활성 이용자 수, 주요 이용 대학·학년 등 규모를 알 수 있는 자료가 있나요?
4. 담당자 성함과 직책은 어떻게 되나요?

**B. 제안 내용**
5. 생각하시는 “공동 프로모션”은 어떤 형태인가요? (예: 게시물 소개, 이벤트, 제휴 페이지 등)
6. 진행 채널과 노출 방식은 무엇인가요?
7. 희망 기간과 시작 시점은 언제인가요?
8. 비슷한 앱·서비스와 진행한 사례와 결과 자료가 있나요?

**C. 비용·조건**
9. 비용(광고비, 수수료 등)이 발생하나요? 발생한다면 구조는 어떻게 되나요?
10. 저희 쪽에 기대하시는 것(혜택 제공, 콘텐츠 제작, 비용 등)은 무엇인가요?
11. 계약서가 필요한 형태인가요?

**D. 데이터·개인정보**
12. 진행 중 회원 정보나 이용자 데이터를 주고받아야 하는 부분이 있나요?
13. 성과는 어떤 기준으로, 어떻게 공유하시나요?

**E. 미팅**
14. 미팅은 온라인·오프라인 중 어느 쪽을 원하시고, 참석 인원은 어떻게 되나요?
15. 미팅 전에 제안서를 먼저 받아볼 수 있을까요?

## 5. 선택지
| 선택지 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **A (권장)** | 회신으로 회사 소개·제안서·질문 답변 요청. 미팅은 자료 검토 후 결정 | 신원 확인 가능, 일정 부담 없음 | 상대 응답까지 시간이 걸림 |
| B | 바로 미팅 일정 제안 | 빠르게 내용 파악 | 신원·비용 불명 상태에서 시간 투입. 출시 주간과 겹칠 수 있음 |
| C | 정중히 거절 | 리소스 절약 | 대학생 스터디 타깃 기회를 놓칠 수 있음 |
| D | 보류(응답 안 함) | 당장 부담 없음 | 응대 공백. 권장하지 않음 |
