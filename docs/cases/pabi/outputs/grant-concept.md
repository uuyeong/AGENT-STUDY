# 외국인 K-pop 팬 대상 한국어 교육 콘텐츠 우선 검증안

## 핵심 요약

- tv파비를 활용한 ‘방송에서 접한 표현을 한국어로 말해 보고 파비와 짧게 대화하기’를 우선 후보로 추천한다. tv파비 활용과 한국어 교육은 기획 방향이지만[e-fixed-concept], 방송 연계 대화는 아직 제안이다[e-fan-concept]. 실제 방송 클립·원곡 가사·아티스트 음성 없이도 학습 경험을 먼저 시험한다.
- 확인 가설은 팬이 관심 있는 장면을 계기로 한국어 발화를 반복한다는 것이다. 해외 학습자 인터뷰와 발화 연습 시험을 먼저 진행하고[e-prototype], 참여·이해·재발화 결과를 확인한 뒤 확장 여부를 판단한다. 신청 자격과 콘텐츠 적합성은 해당 연도 공식 공고로 확인하기 전까지 보류한다[e-grant-year][e-grant-fit].

## 세부 항목

### 우선 후보 — 장면에서 시작하는 한국어 말하기

- **콘텐츠 후보** 방송에서 접할 법한 상황을 자체 제작한 짧은 한국어 대화와 발화 과제로 바꾸는 안. 방송 시청과 한국어 대화를 잇는 선행 제안을 축소해 검증한다[e-fan-concept].
- **대상·학습 장면** 외국인 K-pop 팬이 관심 있는 상황의 표현을 듣고, 파비에게 직접 말한 뒤 다른 문장으로 다시 말해 본다. 이 학습 수요와 반복 의사는 가설이며 인터뷰로 확인한다[e-prototype].
- **기기·앱 역할** tv파비는 상황 제시와 대화 진입점, 앱은 표현 확인·발화 연습·피드백을 맡는 설계안이다. 파비가 인형인지 키링인지는 미정이므로 특정 형태의 조작 방식은 전제하지 않는다[e-form-open].
- **지원사업 관련성** 한국어 교육과 tv파비 활용이라는 기획 방향에 맞춘 후보[e-fixed-concept]. 지원사업 적합성이나 선정 가능성을 뜻하지는 않는다. 선행 [지원 요건 검토](grant-requirements.md)의 확인 항목을 해당 연도 공식 공고와 대조해야 한다[e-grant-year][e-grant-fit].
- **필요 기술·데이터** 자체 작성 상황 대본, 학습 표현, 음성 입력·인식, 발화에 대한 피드백 설계가 필요하다. 인식 정확도와 학습 효과는 실측 전 미확인이다[e-prototype].
- **권리·구현 확인 사항** 초기 시험에는 원곡 가사·아티스트 음성·영상·실제 방송 자료를 넣지 않는다. 이를 쓰려면 자산별 권리와 이용 범위를 확인한다[e-rights]. 아리랑 제공 자료의 내용과 이용 가능 범위, 파비의 기기 형태 및 연동 방식도 확인 전에는 기능에 반영하지 않는다[e-form-open].
- **검증 방법** 해외 학습자에게 자체 제작 상황을 보여 주고 발화 과제를 시험한다[e-prototype]. 상황 이해, 실제 발화 여부, 재발화 의사와 막힌 지점을 관찰한다. 참여나 피드백 품질이 확인되지 않으면 콘텐츠 확장을 보류한다.

### 대안 후보 — 파비에게 한국어 가르치기

- **콘텐츠 후보** 사용자가 파비에게 표현을 가르치고, 파비의 응답을 고치며 다시 말하는 음성 대화안[e-learning-loop].
- **대상·학습 장면** 외국인 K-pop 팬이 좋아하는 주제에 관해 짧은 문장을 만들어 파비에게 설명한다. 설명하는 행위가 발화 반복에 도움이 되는지는 가설이다.
- **기기·앱 역할** tv파비는 대화 상대, 앱은 표현 예시와 대화 기록 확인을 맡는 설계안이다. 실제 입력·출력 방식은 기기 형태가 정해진 뒤 검토한다[e-form-open].
- **지원사업 관련성** tv파비 활용과 한국어 교육 방향에 부합하는 기획 후보[e-fixed-concept]. AI 기술 및 교육 콘텐츠 관련 요건은 공식 공고 확인 전까지 충족 여부를 판단하지 않는다[e-grant-conditions][e-grant-fit].
- **필요 기술·데이터** 음성 인식, 대화 상태 관리, 학습자 발화에 맞춘 응답, 오류 피드백 기준, 자체 작성 예문이 필요하다. 대화 품질과 발화 인식 정확도는 시험으로 확인한다[e-prototype].
- **권리·구현 확인 사항** 초기에는 자체 작성 예문과 허가된 음성만 사용한다. 아티스트 음성·원곡 가사를 활용하려면 별도 권리 확인이 필요하다[e-rights]. 파비의 음성 입출력·연동 가능 여부도 미확인이다[e-form-open].
- **검증 방법** 우선 후보와 동일한 학습자에게 짧은 대화를 시험해 실제 발화, 중도 이탈, 응답 오해 사례를 비교한다. 응답 품질 때문에 학습 과제가 흐려지면 후순위로 둔다.

### 후속 후보 — 방송 자료 연계 표현 학습

- **콘텐츠 후보** 이용 가능한 방송 자료가 확인될 경우, 시청 장면의 표현을 학습 과제와 연결하는 확장안[e-fan-concept].
- **대상·학습 장면** 외국인 K-pop 팬이 시청 중 궁금해진 표현을 확인하고 해당 상황을 한국어로 재현한다. 실제 자료 연계가 학습 참여를 높이는지는 미확인이다.
- **기기·앱 역할** tv파비는 시청과 학습 사이의 진입점, 앱은 표현 설명과 말하기 과제를 맡는 설계안이다. 자료 제공 방식과 기기 연동은 확정하지 않는다.
- **지원사업 관련성** 글로벌 학습자 검증과 협업 증빙을 검토할 여지가 있으나[e-grant-partner], 자료 제공이나 협업 성립을 전제하지 않는다. 공식 공고에서 관련 평가·제출 요건을 확인한다[e-grant-year].
- **필요 기술·데이터** 사용 허가를 받은 영상·자막·메타데이터, 표현별 학습 과제와 발화 피드백이 필요하다. 허가 자료가 없다면 자체 제작 상황으로만 시험한다.
- **권리·구현 확인 사항** 아리랑 제공 자료의 범위와 이용 조건은 미정이다. 방송 영상, 아티스트 음성, 원곡 가사 각각의 사용 권한을 확인하기 전에는 제품 구성이나 지원사업 증빙에 포함하지 않는다[e-rights].
- **검증 방법** 권리·자료 범위가 확인되면 자체 제작 상황 과제와 허가 자료 연계 과제를 비교 시험한다. 허가 범위가 확인되지 않으면 이 후보의 구현·대외 제시는 보류하고 우선 후보의 학습 경험만 검증한다.
