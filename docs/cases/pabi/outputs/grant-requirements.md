# 정부지원사업 신청 전 요건 확인표

## 핵심 요약

- 현재 자료만으로는 신청 자격을 확정할 수 없다. 지원 요건 확인을 콘텐츠 기획보다 먼저 진행하기로 했으며[e-grant-ask], 신청 전에는 해당 연도 공식 공고 원문에서 신청 주체·사업 목적·제출 서류·자부담·일정을 대조하는 것을 추천한다.
- 제공된 기획서는 2027년 공고가 아닌 2026년 공고를 기준으로 작성됐다[e-grant-year]. 교육 콘텐츠 적합성, 자체 AI 기술, IP·협업 증빙, 글로벌 검증 계획은 확인 전제의 검토 항목이다[e-grant-fit][e-grant-conditions][e-grant-rights][e-grant-partner].

## 세부 항목

### 신청 전 우선 확인

- **항목** 대상 사업과 신청 자격
- **제공 자료의 내용** 지원 요건 파악을 교육 콘텐츠 방향 개발에 선행하도록 요청했다[e-grant-ask]. 제공 자료에는 신청 자격을 확정할 공식 공고 원문이 없다[e-grant-year].
- **확인 상태** 내부 결정은 확인됨. 대상 사업의 해당 연도 자격·접수 일정·제출 서류는 미확정.
- **확인 방법** 지원하려는 사업명과 공고 연도를 특정한 뒤 주관기관 공식 공고 원문 및 신청 안내에서 신청 주체, 업력·소재지 등 자격, 접수 기간, 필수 서류를 확인한다. 불명확한 항목은 공고 담당 창구에 질의한다.
- **기획에 미치는 영향** 자격과 일정이 확인되기 전에는 신청 가능 또는 접수 준비 완료로 표시하지 않는다. 확인 결과에 따라 신청 주체와 콘텐츠 기획 범위를 정한다.

### 교육 콘텐츠의 사업 목적 적합성

- **항목** 외국인 K-pop 팬 대상 한국어 교육 콘텐츠의 적합성
- **제공 자료의 내용** 교육 성격 콘텐츠가 사업 목적에 맞는지는 기존 기획서에서도 사전 확인 항목으로 남아 있다[e-grant-fit].
- **확인 상태** 미확정. 콘텐츠 방향은 제안이며 적합 판정을 받은 상태가 아니다.
- **확인 방법** 공식 공고의 지원 목적·지원 분야·제외 대상을 콘텐츠의 핵심 사용 장면과 대조하고, 경계가 모호하면 공고 담당 창구에 콘텐츠 구성과 수익 모델을 설명해 질의한다.
- **기획에 미치는 영향** 적합성이 확인되면 학습자 대상, 반복 사용 장면, 콘텐츠 성과를 구체화한다. 부적합하면 해당 사업에 맞추기 위해 교육 목적을 임의로 바꾸기보다 다른 사업을 검토한다.

### 기술 및 평가 기준

- **항목** 자체 AI 기술 요건과 평가 항목·배점
- **제공 자료의 내용** 기존 기획서는 자체 AI 기술 관련 내용을 2026년 공고 요건으로 정리했으나 공식 원문 대조가 필요하다[e-grant-conditions]. 기존 기획서는 공고, 선정 결과, 외부 자료, 자체 유추를 구분해 표기한다[e-grant-source].
- **확인 상태** 2026년 공고 요약 수준. 자체 기술의 필수 여부·인정 범위와 평가 배점은 미확정이며, 과거 선정 사례는 현재 공고의 요건이나 배점을 증명하지 않는다.
- **확인 방법** 해당 연도 공식 공고, 신청서 양식, 평가표·FAQ에서 자체 기술의 정의, 증빙 방식, 평가 항목과 배점을 대조한다. 과거 선정 사례는 별도로 확인해 참고 사례로만 기록한다.
- **기획에 미치는 영향** 확인 전에는 외부 AI 도구 활용을 자체 AI 기술로 기재하거나 특정 배점에 맞춰 선정 가능성을 예측하지 않는다. 기술 증빙 가능 범위에 맞춰 기능을 정한다.

### 권리와 협업 증빙

- **항목** K-pop 관련 IP·아리랑 협업 및 제출 문서
- **제공 자료의 내용** 기존 기획서는 IP와 협업 문서를 2026년 공고 관련 항목으로 정리했으며 원문 대조가 필요하다[e-grant-rights]. 아리랑 협업이 지원사업에 미치는 영향은 확인 요청 사항이다[e-grant-partner].
- **확인 상태** 권리 확보, 협업 성립, 해당 문서의 필수 제출 여부 모두 미확정.
- **확인 방법** 공식 공고에서 권리·협업 증빙의 제출 요건과 시점을 확인한다. 사용할 음원·영상·상표 등의 권리자와 사용 범위를 확인하고, 협업은 상대 기관의 서면 확인 문서가 있는 경우에만 증빙 가능성을 검토한다.
- **기획에 미치는 영향** 증빙 전에는 특정 IP 사용이나 아리랑 협업을 확정 요소로 넣지 않는다. 권리 확보가 어려우면 권리 의존도가 낮은 교육 콘텐츠로 첫 버전 범위를 조정한다.

### 예산과 글로벌 검증

- **항목** 자부담·해외 수요 검증·피칭 요건
- **제공 자료의 내용** 기존 기획서는 자부담, 검증, 피칭을 2026년 공고 관련 항목으로 정리했으나 공식 원문 대조가 필요하다[e-grant-rights].
- **확인 상태** 자부담 비율·인정 비용, 글로벌 검증·피칭의 필수 여부와 방식은 미확정. 실험 결과나 해외 수요가 이미 확인됐다는 근거는 없다.
- **확인 방법** 해당 연도 공식 공고와 사업비 편성 지침에서 자부담 및 인정 비용을 확인한다. 평가·수행 지침에서 해외 검증과 피칭의 요구 수준을 확인한 뒤, 대상 국가·모집 경로·참여 동의·행동 지표를 포함한 검증 계획을 작성한다.
- **기획에 미치는 영향** 자부담을 감당할 수 있는지 먼저 판단한다. 글로벌 검증이 요구된다면 제안 단계의 판단 기준으로 대상 학습자의 학습 시작률·재방문율을 분모와 관찰 기간을 정해 측정하고, 관찰 결과에 따라 계속·수정·중단을 결정한다. 목표치는 실측치와 구분해 제시한다.
