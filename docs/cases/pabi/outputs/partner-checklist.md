# 아리랑TV 협업 미팅 안건 초안: 자료·권한 확인표

이 문서는 협의할 질문을 정리한 초안이다. 협업 성립, 계약 체결, 자료 제공 또는 출연자 참여가 확인됐다는 뜻이 아니다. 실물 AI 굿즈 사업은 정부지원사업용 한국어 교육 콘텐츠와 목표·납품이 별개다.[two-projects]

아래 모든 항목에서 공통으로 확인할 사항은 ① 실제 제공 가능 여부와 제공 주체 ② 앱·실물 기기·홍보물별 사용 범위 ③ 허용 지역과 기간 ④ 공개 전 심사 및 승인권자 ⑤ 갱신 조건 ⑥ 오류·편성 변경 시 정정 절차 ⑦ 제공 중단·사용 철회 절차다. 답변은 구두 가능성과 확정 권한을 구분해 기록한다.[partner-data]

| 안건 | 미팅 질문 | 미제공·미승인 시 대체 및 다음 판단 |
|---|---|---|
| 공식 일정·편성 | 공개 일정 중 앱 알림에 사용할 수 있는 항목은 무엇인가? 별도 제공이 가능하다면 제공 형식·주기, 시간대 표기, 변경·취소 통지 담당자는 누구인가? SHOW K-POP 공식 안내에는 월요일 18시 KST 생방송이 소개돼 있지만, 이것이 파비용 데이터 제공 승인은 아니다.[public-show][goods-app-first] | 별도 제공이 없다면 공식 페이지 링크와 공개 정보만을 대상으로 정확도·알림 운영 가능성을 검토한다. 변경·취소를 제때 반영할 방법이 없으면 선제 알림 약속을 보류한다.[goods-app-first][goods-weekly] |
| 프로그램 역사·인터뷰 소재 | 프로그램 소개, 과거 방송, 인터뷰 중 제공 가능한 소재가 있는가? 원문·이미지·영상·발언의 권리자는 각각 누구이며, 발췌·요약·번역·굿즈 수록·홍보 사용을 별도로 허용할 수 있는가? | 승인 범위가 확인되지 않으면 해당 소재를 넣지 않는다. 자작 예시와 공식 소스 링크 중심의 초안을 검토한다. 짧은 분량이라는 이유만으로 사용 가능하다고 판단하지 않는다.[rights] |
| 출연자 질문·답변지 | 회차 후 팬 질문용으로 제공 가능한 질문지나 답변지가 있는가? 출연자·소속사 등 추가 승인권자가 있는가? 제공 주기, 엠바고, 사실 오류 정정과 삭제 요청은 어떻게 처리하는가? | 제공·재사용 권한이 확인되지 않으면 ‘출연자 답변’으로 표시하지 않는다. 자작 질문을 활용한 일반 팬 활동 대화로 대체할지 판단한다.[goods-exclusive][goods-weekly] |
| 인사 녹음 재생 | 실제 짧은 인사 녹음을 제공할 수 있는가? 제공된다면 원본·편집본의 재생 매체, 다운로드·재판매, 지역·기간, 출연자 승인 범위는 어디까지인가? | 녹음과 재생 권한이 모두 확인되기 전에는 음성팩을 판매 범위에 넣지 않는다. 파비 기본 음성 사용을 검토한다.[goods-exclusive][rights] |
| 음성 합성 | 녹음 재생과 별개로, 특정 출연자의 음성을 학습·합성하거나 새로운 발화를 생성할 권한을 부여할 수 있는가? 학습 자료 처리·보관, 결과물 심사, 철회 시 모델·결과물 처리 기준은 무엇인가? | 별도 권한이 없으면 합성하지 않는다. 녹음 재생 승인만으로 합성 승인을 추정하지 않는다.[goods-exclusive] |
| 투표 | 공식 투표와 연동하거나 유료 사용자에게 혜택을 제공할 권한이 있는가? 투표 운영 주체, 적용 규정, 유료 배정 가능 여부와 승인권자는 누구인가? 공식 안내에 팬 투표 참여 경로가 있다는 사실은 파비의 투표 혜택 권한을 뜻하지 않는다.[public-show][goods-voting] | 권한·규정이 확인되지 않으면 투표 혜택을 상품이나 구독 이유로 제시하지 않는다. 회의에서 나온 지불 의향 발언도 구매 검증으로 취급하지 않는다.[goods-voting] |
| 방송 이용·동기화 | 방송 소리 또는 공식 라이브 서버 데이터를 앱이 수신·처리·보관할 수 있는가? 허용 지역, 해외 시청 시차, 지연 동기화에 필요한 접근 조건과 승인권자는 누구인가? | 방송 접근·처리 권한과 동기화 가능성이 확인되지 않으면 라이브 반응 기능을 약속하지 않는다. 방송 없이 작동하는 팬 활동 흐름을 먼저 검토한다.[goods-live] |
| 브랜드·판매 채널 | 아리랑TV·프로그램 명칭과 로고를 제품, 포장, 앱, 광고에 각각 사용할 수 있는가? 승인 문구·디자인 심사권자는 누구인가? 양측 판매 채널, 판매 지역, 판매 주체, 고객 응대·반품 책임은 어떻게 나눌 수 있는가? | 명칭·로고와 채널 사용이 승인되기 전에는 ‘공식 협업 굿즈’로 표시하거나 판매 채널을 확정하지 않는다. 브랜드를 쓰지 않는 MVP 범위를 별도로 판단한다.[partner-data][two-projects] |

사업 담당자 기록란: 항목별로 ‘제공 가능 여부 / 권리·승인권자 / 허용 범위·지역·기간 / 심사·갱신·정정·철회 / 제공 주기 / 미제공 시 대체 / 확인 자료와 다음 확인일’을 남긴다. 답변이나 문서 근거가 비어 있는 항목은 미확정으로 유지하고, 권한 증빙과 운영 조건을 받은 뒤 제품 범위·카피·판매 실험 포함 여부를 결정한다.[partner-data][rights]
