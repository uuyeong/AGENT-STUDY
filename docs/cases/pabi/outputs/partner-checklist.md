# 아리랑TV 협업 미팅 안건 초안: 제공 자료·권한 확인표

## 핵심 요약

- 아리랑TV 공식 안내에는 SHOW K-POP의 월요일 18시 KST 생방송과 팬 투표 경로가 소개돼 있지만, 이는 파비에 대한 자료 제공이나 재사용 승인을 뜻하지 않는다.[public-show]
- 미팅에서는 자료 제공 여부와 용도별 권한을 먼저 확인한다. 답변지·음성, 방송 처리, 유료 투표 혜택은 모두 미확정이다.[goods-exclusive][goods-live][goods-voting][partner-data]
- 제공이나 권한이 확인되지 않은 항목은 판매 범위에서 제외하고, 방송 없이 작동하는 콘텐츠 루프를 대안으로 검토한다.[goods-live][rights]

## 미팅 목적과 전제
이 문서는 협업 가능성을 검토하기 위한 질문 초안이다. 협의 성립, 계약 체결, 출연자 참여를 전제하지 않는다. 공식 방송 안내의 일정과 투표 경로는 확인됐지만, 파비의 자료 이용 권한은 별도 확인이 필요하다.[public-show]

## 항목별 확인 질문
- 공식 일정·편성: 일정과 변경 정보를 제공할 수 있는가? 제공한다면 전달 방식과 주기, 편성 변경·오보 정정 담당자와 통지 시점은 무엇인가? 제공하지 않으면 공식 안내 페이지 링크만 사용할 수 있는가?[public-show][partner-data]
- 역사·인터뷰 소재: 제공 가능한 프로그램 소개, 과거 회차 정보, 인터뷰 자료가 있는가? 각 자료의 권리자와 출처는 누구이며, 요약·번역·유료 상품 활용이 가능한가? 미제공 시 공개 정보 링크와 자작 설명만 사용하는 안을 검토할 수 있는가?[partner-data][rights]
- 출연 아티스트 질문·답변지: 질문지나 백스테이지 답변을 제공할 수 있는가? 출연자별 동의, 공개 시점, 회차 후 해금, 수정·삭제 요청 절차는 무엇인가? 미제공 시 해당 기능을 제외한다.[goods-exclusive]
- 녹음 재생·음성 합성: 짧은 인사 녹음 또는 음성팩 제공 가능 여부와 녹음·실연 관련 권리자를 확인한다. 승인된 원본 녹음의 재생, 편집, 유료 판매, 재판매, 음성 합성을 각각 허용하는가? 합성 권한이 없으면 파비 기본 음성만 사용하는 안을 검토한다.[goods-exclusive][rights]
- 방송 소리·화면: 방송을 파비가 수신·처리할 수 있는가? 실시간 수신, 저장, 재전송, 발췌, 해외 이용을 각각 허용하는가? 시청 지연에 따른 동기화 기준과 처리·보관 조건은 무엇인가? 권한이나 성능을 확인하지 못하면 방송 연동 없이 작동하는 콘텐츠 루프를 먼저 검토한다.[goods-live]
- 투표: 공식 팬 투표와 별도로 파비 구매·구독에 연결할 수 있는 유효한 혜택이 있는가? 가능하다면 운영 주체, 규정, 유료 배정 허용 여부, 지역·연령 제한, 결과 정정 절차는 무엇인가? 확인 전에는 구매 혜택으로 제시하지 않는다. 기존 지불 의향 발언 한 건은 시장 검증으로 취급하지 않는다.[public-show][goods-voting]
- 브랜드·판매 채널: 프로그램명·로고·출연자 이름과 이미지의 상품 표기 및 홍보 사용을 각각 허용하는가? 앱, 실물 굿즈, 파트너 채널, 자체 판매 채널별 승인 주체와 판매 가능 지역은 어디인가? 권한이 없으면 해당 표기와 소재를 제외한 자체 상품안을 검토한다.[rights][partner-data]

## 모든 제공 항목에 공통으로 확인할 조건
- 사용 범위: 앱·실물·광고·유료 판매별 허용 행위와 금지 행위는 무엇인가?
- 지역·기간: 이용 및 판매 가능 지역, 시작일·종료일, 종료 후 재고·구매자 접근 처리 기준은 무엇인가?
- 심사·갱신: 원고·디자인·기능 심사 대상, 승인권자, 소요 기간, 갱신 조건은 무엇인가?
- 제공·정정·철회: 자료 제공 책임자와 주기, 오류·편성 변경 통지 방식, 권리자 요청에 따른 정정·철회 절차는 무엇인가? 미제공 또는 철회 시 대체 콘텐츠를 사용할 수 있는가?[partner-data]

## 미팅 후 판단 기록
각 항목을 ‘제공 가능 여부 / 권리자·승인권자 / 허용 용도·지역·기간 / 심사·정정·철회 조건 / 미제공 시 대체안 / 확인 문서와 담당자’로 기록한다. 구두 논의와 서면 승인을 구분한다. 답변이나 승인 문서가 없는 항목은 미확정으로 두고, 해당 소재를 포함한 카피·판매 범위 결정을 보류한다. 공표 저작물 인용에 일률적인 ‘30초 허용’ 기준을 적용하지 않는다.[rights]
