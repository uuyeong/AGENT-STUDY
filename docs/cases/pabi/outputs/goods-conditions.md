# AI 굿즈 협업·판매 조건 확인표

## 핵심 요약

- [기능 후보 검토](goods-review.md)의 앱 팬토크·알림 우선 검토와 실물 확장은 선행 제안이며, 출시 순서는 확정되지 않았다.[e10]
- 아티스트 답변·음성, 방송 소재, 투표·구독 혜택은 제공·사용이 확정되지 않은 후보로 둔다.[e13][e20][e14] 권리와 구현 조건을 확인한 앱 경험만 첫 검증 대상으로 제안한다.

## 세부 항목

### 팬토크: 아티스트 답변

- **연결 기능** [기능 후보 검토](goods-review.md)의 앱 팬토크 후보
- **필요 소재·협업** 아티스트 답변 제공 및 판매 경험 내 사용 협의
- **현재 확인 수준** 답변 제공 여부는 미확인이다.[e13]
- **권리·정책 확인 사항** 사용 목적·기간, 편집·재사용 범위와 팬에게 안내할 제공 방식을 확인한다.
- **확인 방법** 아티스트 측 권리·운영 담당자에게 제공 가능 여부와 허용 범위를 서면 확인하고, 내부 제품 담당자에게 구현할 동작을 확인한다.
- **미확인 시 대안** 아티스트 답변을 팬토크 혜택과 판매 문구에서 제외한다.

### 팬토크: 녹음 재생과 합성 음성

- **연결 기능** [기능 후보 검토](goods-review.md)의 앱 팬토크 후보
- **필요 소재·협업** 녹음 음성의 재생과 합성 음성의 제작·사용을 별도 협의
- **현재 확인 수준** 녹음 제공 여부와 재생·합성 각각의 사용 권리는 미확인이다.[e13]
- **권리·정책 확인 사항** 녹음 재생은 원본의 제공·복제·재생 범위를, 합성 음성은 생성 허락과 생성물의 사용·고지 범위를 따로 확인한다. 한 방식의 허락을 다른 방식에 적용하지 않는다.
- **확인 방법** 아티스트 측과 녹음 권리 담당자에게 방식별 허용 범위를 서면 확인하고, 내부 제품 담당자에게 실제 구현 방식을 확인한다.
- **미확인 시 대안** 권리가 확인되지 않은 음성 방식과 관련 판매 문구를 제외한다.

### 방송 소재를 활용한 팬 경험

- **연결 기능** [기능 후보 검토](goods-review.md)의 앱 팬 경험 및 실물 확장 후보
- **필요 소재·협업** 의상·영상·인터뷰 소재의 제공 및 용도별 사용 협의
- **현재 확인 수준** 소재 사용 시 용도별 권리 범위 확인이 필요하다.[e20]
- **권리·정책 확인 사항** 앱 화면·홍보물·실물 상품의 용도를 구분해 소재별 사용·편집·배포 범위를 확인한다.
- **확인 방법** 소재 보유·권리 담당자에게 권리자와 용도별 허용 범위를 서면 확인한다.
- **미확인 시 대안** 권리가 확인되지 않은 소재를 기능 시안과 판매 문구에서 제외한다.

### 투표·구독 혜택 연동

- **연결 기능** [기능 후보 검토](goods-review.md)의 팬 경험과 연결할 외부 혜택 후보
- **필요 소재·협업** 스트리밍 또는 투표 파트너와 혜택 제공·연동 조건 협의
- **현재 확인 수준** 스트리밍 또는 투표 파트너와 구독 혜택을 만드는 방안은 제안 단계이며, 제공 조건은 확인되지 않았다.[e14]
- **권리·정책 확인 사항** 제공 주체, 대상·기간, 참여·구독 확인 방식, 운영 책임과 판매 문구에 쓸 수 있는 범위를 확인한다.
- **확인 방법** 해당 혜택 운영 주체에게 제공 가능 여부와 조건을 서면 확인하고, 내부 제품 담당자에게 연동 가능 범위를 확인한다.
- **미확인 시 대안** 투표·구독 혜택을 판매 조건과 카피에서 제외한다.

### 실물 확장의 판매 조건

- **연결 기능** [기능 후보 검토](goods-review.md)의 실물 확장 후보
- **필요 소재·협업** 기기 구성과 가격·구독료 및 포함 혜택의 내부 결정
- **현재 확인 수준** 실물 확장은 선행 문서의 후보 제안이다.[e10] 기기 구성·가격·구독료는 확인이 필요하다.[e12]
- **권리·정책 확인 사항** 실물에 포함할 기능·소재의 권리 범위를 확인한 뒤 가격·구독료와 실제 제공 범위가 일치하는지 검토한다.
- **확인 방법** 내부 제품·사업 담당자에게 구성과 판매 조건의 결정 여부를 확인한다. 소재를 포함한다면 해당 권리 담당자에게 사용 범위를 별도로 확인한다.
- **미확인 시 대안** 실물의 가격·구독료·포함 혜택을 확정 문구로 제시하지 않고 앱 경험의 조건 확인을 우선한다.
