# 파비 AI 굿즈 기능·판매 우선순위안

## 핵심 요약

- 매니저형 일정 알림을 앱에서 먼저 검증하고, 반복 사용이 확인되면 로봇 연계를 검토하는 안을 추천한다. 매니저 방향은 선택됐지만 구체 동작은 미정이며[e-manager], 앱 선검증·실물 확장은 선행 문서의 제안이다[e-app-first].
- 셀링 포인트는 ‘팬의 일정을 챙기는 파비’로 한정한다. 아티스트 답변·음성·방송 데이터와 투표 혜택은 권리·파트너 조건 확인 전 판매 약속에서 제외한다[e-exclusive][e-vote][e-rights].
- 2주간 일정 알림과 팬토크 후보의 재사용률·구매 의향 행동을 같은 기준으로 비교한다. 가격은 후보로만 두고, 설문 응답과 실제 결제는 별도로 판단한다[e-price].

## 세부 항목

### 1순위: 앱 매니저형 일정 알림

- **기능·판매안** 팬이 등록한 관심 일정의 알림을 앱에서 먼저 시험한다. 앱 사용 → 재사용 확인 → 로봇 관심 등록 순으로 검토한다. 매니저 방향은 내부에서 선택됐으나 세부 동작은 미정이다[e-manager]. 앱 선검증과 실물 확장은 선행 제안이다[e-app-first].
- **대상 팬과 사용 장면** 일정을 놓치고 싶지 않은 팬이 알림을 확인하는 장면을 가정한다. 처음 쓰는 이유는 일정 확인의 편의, 다시 쓰는 이유는 다음 일정에도 알림이 필요한지 검증한다. 대안은 팬이 쓰는 기존 캘린더·알림 수단이다.
- **앱·로봇 역할** 앱은 일정 등록·알림·반응 측정 후보로 둔다. 로봇은 앱 경험을 선호하는 팬에게 제안할 실물 접점으로만 둔다. 로봇의 알림 동작과 연동 가능 여부는 제품팀 확인 전 약속하지 않는다.
- **셀링 포인트** 초안: ‘관심 일정을 파비와 함께 챙겨보세요.’ 확인되지 않은 공식 일정 제공이나 자동 연동은 표현하지 않는다.
- **필요한 협업·권리** 일정 출처, 갱신 책임, 알림 발송 범위와 앱·로봇 구현 가능 범위를 제품·제휴 담당자가 확인해야 한다. 외부 일정 데이터를 쓸 경우 제공 조건도 확인한다.
- **확인할 가설** 제안: 일정 알림은 팬토크 후보보다 2주 내 재사용률이 높다. 일정 편의가 첫 사용과 반복 사용 모두의 이유인지는 별도로 확인한다.
- **검증 방법** 제안: 동의한 시험 사용자에게 2주간 일정 알림안과 팬토크안을 같은 노출 조건으로 비교한다. 재사용률의 분모는 각 안을 실제 사용한 고유 사용자, 분자는 2주 내 다른 날 다시 사용한 사용자로 둔다. 사전 판단 기준은 일정 알림안의 재사용률이 팬토크안보다 높고, 로봇 관심 등록도 발생하는지다. 관심 등록은 결제가 아닌 별도 지표로 기록한다.

### 2순위 후보: 팬토크

- **기능·판매안** 팬토크는 일정 알림과 비교할 앱 후보로 둔다. 답변 범위가 확정되기 전에는 아티스트가 직접 답하는 상품으로 판매하지 않는다.
- **대상 팬과 사용 장면** 대화형 경험을 원하는 팬이 앱을 열어 질문하는 장면을 가정한다. 첫 사용 이유는 대화에 대한 호기심, 반복 사용 이유는 답변 경험의 지속 가치로 나눠 검증한다. 대안은 기존 팬 커뮤니티 콘텐츠다.
- **앱·로봇 역할** 앱에서 허용된 답변 범위의 만족도와 재사용을 확인한다. 로봇 대화는 음성 권리와 구현 범위가 확인된 뒤에만 후보로 검토한다.
- **셀링 포인트** 권리 확인 전 초안: ‘파비와 대화해 보세요.’ 아티스트 답변·목소리·방송 장면을 제공한다고 표현하지 않는다.
- **필요한 협업·권리** 아티스트 답변·녹음의 제공 여부와 사용 권리는 미확인이다[e-exclusive]. 원곡 가사·음성의 이용 범위도 확인이 필요하다[e-rights]. 방송 데이터는 제공 주체, 학습·검색·표시 허용 범위, 기간을 별도로 서면 확인해야 한다.
- **확인할 가설** 제안: 허용된 자료만 사용하는 팬토크도 일정 알림과 비교할 만한 재사용을 만든다. 아티스트 자료가 없을 때의 경험과 권리 확보 후 경험은 같은 상품으로 간주하지 않는다.
- **검증 방법** 제안: 권리 확인 전에는 허용된 시험 문구만으로 2주간 사용성을 비교한다. 분모는 팬토크를 실제 사용한 고유 사용자, 분자는 2주 내 다른 날 다시 사용한 사용자다. 일정 알림안보다 재사용률이 낮으면 우선순위를 낮추고, 높더라도 권리 확인 전에는 아티스트 연계 상품으로 전환하지 않는다.

### 판매 흐름·가격·제휴 조건

- **기능·판매안** 제안: 앱 경험 확인 → 실물 관심 등록 → 제공 범위와 권리 확인 → 가격·구성 제시 → 판매 여부 판단 순으로 진행한다. 앱 알림 선시험과 실물 확장은 선행 제안이다[e-app-first]. 가격과 구독료는 구성도 정해지지 않은 후보로만 둔다[e-price].
- **대상 팬과 사용 장면** 앱의 반복 사용자는 로봇 연계 관심을 확인할 대상이다. 실물을 먼저 원하는 팬은 별도 관심 등록으로 구분한다. 앱과 실물 각각의 구매 이유를 묻고, 기존 앱 알림·일반 굿즈를 대안으로 비교한다. 유통 접점은 권리와 판매 주체가 확인된 공식 제휴 채널을 후보로 둔다.
- **앱·로봇 역할** 앱은 기능 수요와 반복 사용을 확인하는 접점이다. 로봇은 별도 지불 의향과 실제 구매 행동을 확인해야 하는 상품 후보이며, 앱 성과를 로봇 판매량으로 환산하지 않는다.
- **셀링 포인트** 초안: ‘먼저 앱에서 파비를 써보고, 실물 파비가 필요한지 선택하세요.’ 앱 체험의 제공 방식과 실물 판매 조건이 확정된 뒤에만 대외 문구로 다듬는다.
- **필요한 협업·권리** 아리랑TV 및 관련 권리자와 명칭·콘텐츠·판매 채널·수익 배분·고객 지원 책임을 협의해야 한다. 스트리밍·투표 혜택은 파트너 정책 확인이 필요한 제안이다[e-vote]. 혜택의 제공 주체와 허용 범위를 서면 확인하기 전에는 포함하지 않는다.
- **확인할 가설** 제안: 앱 재사용자 중 일부는 실물 구매에도 관심을 보인다. 제시 가격별 설문 지불 의향, 관심 등록, 실제 결제는 서로 다른 지표로 취급한다. 판매량과 구독 수요는 아직 확인된 사실로 제시하지 않는다.
- **검증 방법** 제안: 2주간 앱 사용자를 대상으로 실물 관심 등록을 받는다. 관심 등록률의 분모는 실물 안내를 본 고유 사용자, 분자는 등록을 완료한 사용자다. 가격·구성·권리 확정 후에만 가격별 구매 선택을 시험하고, 실제 결제가 가능해진 경우 결제율의 분모는 가격을 본 고유 사용자, 분자는 결제 완료자다. 사전 판단 기준은 앱 재사용, 관심 등록, 실제 결제를 각각 확인한 뒤 실물 판매 여부를 결정하는 것이다.
