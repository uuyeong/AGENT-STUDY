## 결정 사항과 적용 범위

내부에서 확인된 사업 구분은 정부지원사업용 K-pop 연계 한국어 교육과 아리랑TV 협업 실물 AI 굿즈의 분리다. 자산 공유 가능성은 있으나 목표와 납품은 합치지 않는다. [two-projects] 교육 기획은 tv파비 활용과 글로벌 한국어 교육을 전제로 한다. 교포 가정·교육기관은 초기 검토 후보이고 기기 외형은 확정되지 않았다. [edu-brief] 따라서 아래의 앱·기기 구성은 제품 확정안이 아니라 실험 설계다.

## 학습 문제와 검증 가설

첫 세그먼트는 초급 성인 해외 K-pop 팬으로 제한한다. 팬사인회·굿즈샵 상황극과 짧은 발화 복습은 제안된 콘텐츠 후보이며, 해외 학습자가 실제로 어디서 막히는지와 우선 난이도는 인터뷰 전이다. [edu-research] [edu-material] [edu-scope] 첫 과제는 가상의 굿즈샵에서 “포토카드는 어디에 있어요?”라고 묻고 안내 뒤 “감사합니다”로 마치는 자작 에피소드다. [learning-episode]

검증 가설: 같은 표현을 설명·읽기만 하는 방식보다, 팬 활동 상황에서 응답을 만들고 다시 말하는 방식이 목표 문장의 독립 발화와 상황에 맞는 사용을 높일 수 있다. 이는 기존 서비스 대비 우위가 확인됐다는 주장이 아니다. 인터뷰에서 학습자가 현재 쓰는 서비스·교재와 불편을 수집하고, 파일럿에서는 동일 목표 표현을 다루는 비교 과제를 마련해 검증한다. [edu-scope] [edu-research]

## 2주 파일럿과 판정 기준 — 제안

1주 차에는 참여자의 한국어 경험과 기존 학습 수단을 기록하고, 도움 없이 굿즈샵 위치 질문·대화 마무리를 수행하는 사전 과제를 녹음 선택 또는 문장 입력으로 받는다. 이후 자작 4턴 에피소드를 사용한다. 2주 차에는 물건 이름과 화면 힌트를 바꾼 동등 난이도 과제로 사후 평가하고, 지연 재시도와 짧은 사용성 인터뷰를 한다. 녹음하지 않아도 진행할 수 있고, 음성 인식이 불확실하면 직접 입력으로 전환한다. [learning-episode]

사전·사후에는 동일한 채점표를 적용한다: 위치 질문의 의미 전달, “어디에 있어요?” 사용, 상황에 맞는 마무리를 각각 0점(수행 못함)·1점(힌트 후 수행)·2점(힌트 없이 수행)으로 기록한다. 음성 과제와 입력 과제는 구분해 비교하며, 점수 외에 힌트 사용·재시도·이탈을 기록한다. 파일럿 착수 전에 표본 수, 비교 과제의 제공 방식, 평가자 간 일치 기준을 정한다.

확장 판단 기준으로는 사전 대비 사후 총점이 오른 참여자 비율, 힌트 없는 질문 완수율, 비교 과제와의 차이를 함께 보고할 것을 제안한다. 합격 수치와 통계적 효과는 표본·운영 조건을 정하기 전 확정하지 않는다. 발화 개선 없이 사용 만족도만 높거나, 인식 실패 때문에 음성 평가가 불가능하면 학습 효과 주장과 확장을 보류한다.

## 앱·기기·AI 검증 범위

앱은 상황 제시, 예시 보기, 문장 입력, 재시도, 학습 기록 확인의 기본 경로로 제안한다. tv파비는 선택적인 대화 입출력 기기로 시험하되, 기기 없이도 같은 학습 과제를 완료할 수 있게 설계한다. 기존 Dasoni의 스트리밍 음성 인식·대화·음성 합성·대화 평가 자산은 문서상 재사용 후보일 뿐이다. 가르침·복습 엔진, 학습자 발화 평가, 기기 연동 성능은 확인되지 않았다. [edu-platform]

신규 검증은 목표 표현에 맞는 피드백 생성, 인식 불확실성 감지와 입력 전환, 복습 시점, 앱·기기 간 진행 상태 유지에 집중한다. 발음 피드백은 음성 인식 결과만으로 정오를 단정하지 않는다. [learning-episode] 동의한 발화 표본을 교육 검토자가 독립 평가하고, 시스템 피드백과 비교해 잘못된 교정·놓친 오류를 집계한다. 의미는 전달되지만 목표 표현이 빠진 경우와 실제 발음 문제를 구분하지 못하면 자동 발음 채점을 배포하지 않는다.

음성 처리는 파일럿 전에 선택 동의, 수집 목적, 접근 권한, 보유 기간, 삭제 요청 경로를 문서화한다. 제안 기본값은 녹음 선택, 원음의 평가 목적 외 사용 금지, 보유 기간 만료 또는 삭제 요청 시 원음·연결 식별정보 삭제다. 실제 보유 기간과 삭제 구현 여부는 확정 전이므로 동의 화면과 삭제 시험으로 확인한다. 음성 보관에 동의하지 않는 참여자는 문장 입력 경로를 이용하도록 한다. [learning-episode]

## 지원사업 제안서 보완과 확장 보류

2026년 한국콘텐츠진흥원 선도형 공고는 이전 공고다. 차기 신청의 자격·평가 기준·일정·자부담으로 그대로 적용하지 않는다. 차기 공고가 공개되면 원문과 내부 기획서의 자격·배점 항목을 대조하고, 적합할 때만 제안서에 반영한다. [public-grant] 보완 자료는 학습자 인터뷰 기록, 비교 과제와 채점표, 파일럿 전후 결과, 기술 재사용 시험, 음성 동의·삭제 시험, 콘텐츠 권리 목록으로 제안한다.

방송 원본, 실존 아티스트 소재와 가사는 용도별 권리 확인 전까지 제외하고 자작 예시와 파비 기본 음성을 우선 사용한다. 저작물의 “30초” 또는 “몇 소절”을 일률적인 허용 기준으로 삼지 않는다. [rights] 자작 표현으로 곡 만들기와 떼창 채점은 원가·권리·학습 효과가 검증되지 않아 확장 보류다. [edu-material] 교포 가정·교실 모드도 필요와 개인정보 요건이 다른 별도 확장 후보로 둔다. [edu-scope] 기기 외형·판매가 역시 이 교육 파일럿의 확정 조건으로 쓰지 않는다. [edu-brief] [price-conflict]

## 리스크와 확인 필요

모든 실행 항목의 담당자와 마감이 미정이다. 면담에서 언급된 “12월 15일 전”은 연도·담당 일정·실제 제출 기한이 확인되지 않은 내부 목표이므로 칸반 마감으로 확정하지 않았다. [edu-deadline] 차기 공고 원문을 확인한 뒤 제출 역산 일정을 제안해야 한다. [public-grant]

확인 필요: 실제 학습자의 주요 말하기 장애와 현재 서비스 대비 차이, 파일럿 모집·평가 담당, 음성 보유 기간과 삭제 구현, Dasoni 및 기기 성능, 발음 피드백의 교육적 정확도, 차기 공고 적합성. 각 항목의 확인 결과가 없으면 효과·기술 준비도·지원 적격성을 확정해 제안서에 쓰지 않는다.
