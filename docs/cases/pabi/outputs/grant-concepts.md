# tv파비 활용 K-pop 한국어 교육 콘텐츠 후보 비교

## 핵심 요약

- 우선 검증 방향은 가사·방송 원본 없이 자체 제작한 K-pop 주제 한국어 표현 학습이다. 화면 시안으로 학습 흐름을 점검하고, 작동하는 시제품으로 7일 내 실제 재학습 행동을 관찰한다. 수요와 구현 가능성은 미확인이다.
- 가사 활용은 기존 자료의 아이디어이고[e04], 실시간 방송 청취 방식에는 권리 검토가 필요하다[e09]. 권리 범위가 확인되기 전에는 두 후보의 원본 자료를 시험·출시 범위에 넣지 않는다.
- 지원 적합성은 [지원사업 근거 검토](grant-basis.md)의 확인 수준에 따른다. 기존 기획서의 공고·평가·선정 사례 정리는 신청 연도 공식 원문과 대조해야 하며[e17][e18][e19][e06], 교육 콘텐츠 적합성도 사전 문의가 필요하다[e07].

## 세부 항목

### 우선 검증 제안: 자체 제작 K-pop 주제 한국어 표현 학습

- **후보** 제안. 가사·방송 원본이나 특정 아티스트 소재를 사용하지 않고 공연 관람·팬 활동 등의 상황에 쓰이는 한국어 표현을 자체 제작한다. 채택 결정은 아니다.
- **대상·경험** K-pop에 관심이 있는 한국어 학습자를 가정한다. 짧은 표현을 보고 뜻을 고른 뒤 복습한다. 새 표현과 이전 표현의 복습이 반복 사용의 이유이며, 일반 한국어 학습 앱이 대체 수단이다. 실제 수요는 미확인이다.
- **기기·앱 역할** 제안: tv파비는 표현·문항 제시와 응답, 앱은 학습 목록과 복습 기록 확인을 맡는다. 기기 형태가 미확정이므로[e03] 입력·음성 기능을 전제하지 않는다. 해당 동작이 불가능하면 앱 단독 흐름과 비교한다. 운영자는 표현·정답과 오류 신고를 관리한다.
- **필요 기술·데이터** 자체 작성 자료의 제작·사용 권리 확인, 문항 관리, tv파비의 표시·입력 동작과 앱 기록 동기화 검증이 필요하다. 응답 실패 시 다시 시도할 수 있는 흐름을 시제품에서 점검한다. 학습 기록의 수집 항목·보관 기간·동의·삭제 방법을 수집 전에 정한다. 첫 버전에서 발음 자동평가와 개인화 추천은 제외한다.
- **근거 수준** 후보와 역할 분담은 제안이며 수요·구현·효과의 확인 결과가 아니다. tv파비 활용과 한국어 교육은 내부 확정 방향이다[e02]. 기존 기획서의 A·E 핵심, C·D 확장 구분 역시 제안이며[e08], 이 후보와의 대응 관계는 확인되지 않았다.
- **검증 방법** 화면 시안으로 학습 흐름을 점검하고, 작동하는 시제품으로 7일 내 실제 재학습 행동을 관찰한다. 제안 지표는 학습 시작자를 분모로 한 완료율과 첫 학습 완료자를 분모로 한 7일 내 재학습률이다. 모집 규모·관찰 기간·통과 기준을 시험 전에 정한다. 기기 입력과 기록 동기화는 별도 시제품 시험으로 확인한다. 결과에 따라 기기 포함 개발, 앱 단독 재설계, 또는 중단을 결정한다. 현재 관찰 결과는 없다.
- **보류 조건** 기기 동작이나 자료 권리가 확인되지 않으면 기기 포함 출시를 보류한다. 신청 연도 공식 공고 대조와 교육 콘텐츠 적합성 문의 전에는 지원 적합성을 확정하지 않는다[e06][e07].

### 조건부 후보: 허락받은 K-pop 가사로 배우는 표현

- **후보** 제안. 이용 허락을 받은 가사의 짧은 구절로 표현을 학습한다. 가사 활용은 기존 자료의 아이디어다[e04].
- **대상·경험** 특정 곡에 관심이 있는 학습자를 가정한다. 구절의 뜻을 익히고 다른 문장에서 같은 표현을 찾아 복습한다. 곡에 대한 관심이 재학습으로 이어지는지는 미확인이다.
- **기기·앱 역할** 제안: tv파비에서 허락된 자료와 문항을 제시하고 앱에서 복습한다. 표시·재생 기능은 확인 후 범위를 정한다. 운영자는 곡별 허락 범위·기간과 철회 요청을 관리한다.
- **필요 기술·데이터** 가사·음원·번역·표시 화면의 권리 주체와 매체·지역·기간·가공 허용 범위를 각각 확인해야 한다. 허락 범위에 따른 자료 배포·회수와 학습 기록의 동의·삭제 절차가 필요하다. 첫 버전에서 권리가 확인되지 않은 음원 재생은 제외한다.
- **근거 수준** 가사 활용은 제안[e04]이다. 이용 권리, 가격, 구현 가능성, 학습 효과와 사업 적합성은 확인되지 않았다. 기존 자료만으로 권리 안전성을 단정하지 않는다.
- **검증 방법** 권리자와 관련 계약 주체에게 사용 조건을 확인한 뒤 허락된 범위에서만 시제품을 시험한다. 학습 시작자를 분모로 한 완료율, 첫 학습 완료자를 분모로 한 7일 내 재학습률을 자체 제작 후보와 비교한다. 관찰 기간·통과 기준을 사전에 정하고, 권리 조건과 행동 결과를 함께 보고 확대 또는 보류를 결정한다. 현재 결과는 없다.
- **보류 조건** 필요한 권리와 사용 조건이 확인되지 않으면 원본 자료를 탑재하거나 이용자 시험에 쓰지 않는다. 비용·범위가 정해지기 전에는 출시 규모와 사업비를 확정하지 않는다.

### 후순위 후보: 방송 소재를 활용한 듣기 학습

- **후보** 제안. 방송 속 한국어 발화를 듣고 핵심 내용을 고르는 학습이다. 실시간 청취와 녹화·발췌 제공은 별도 방식으로 검토한다.
- **대상·경험** 실제 발화를 짧게 듣고 싶은 학습자를 가정한다. 방송 시간에 맞춘 학습과 원하는 때 반복하는 학습 중 어느 방식이 유효한지는 미확인이다.
- **기기·앱 역할** 제안: tv파비는 청취와 문항 응답, 앱은 복습 목록을 맡는다. 운영자는 사용 가능한 자료, 게시 기간, 권리 변경과 오류 신고를 관리한다. 송출·재생·응답 기능은 검증 전제다.
- **필요 기술·데이터** 방송 영상·음성, 출연자·음악 등 포함 소재, 자막과 발췌·재전송 권리를 각각 확인해야 한다. 자료 출처·갱신 주기와 권리 철회 시 중단·삭제 절차가 필요하다. 재생 실패 시 재시도 흐름, 전달 지연과 재생 안정성은 시제품 시험 대상이다.
- **근거 수준** 후보는 제안이다. 기존 자료에는 실시간 방송 청취 방식의 저작권 검토 필요성이 적혀 있다[e09]. 방송 이용 권리, 외부 협의 결과, 기술 성능과 사업 평가상 이점은 확인되지 않았다. 아리랑TV 협업의 평가 영향도 제공된 근거로 확인되지 않는다.
- **검증 방법** 자료별 권리와 협의 주체를 먼저 확인한다. 허용 범위가 정해진 뒤에만 재생·응답 시제품을 시험한다. 청취 시작자를 분모로 완료율과 재시도율을 기록하고, 관찰 기간·통과 기준을 사전에 정한다. 권리 범위와 시험 결과에 따라 실시간·발췌 방식 중 후속 검토 대상을 정하거나 중단한다. 현재 결과는 없다.
- **보류 조건** 방송과 포함 소재의 이용 범위가 확인되지 않거나 필요한 재생 동작이 작동하지 않으면 해당 방식의 시험·출시를 보류한다. 공식 공고 확인과 사전 문의 전에는 교육 콘텐츠 적합성을 지원 근거로 주장하지 않는다[e06][e07].
