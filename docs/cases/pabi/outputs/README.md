### 정부지원사업·한국어 교육 콘텐츠

- **판단** 제공된 기획서는 2026년 공고를 기준으로 작성돼 신청 요건을 확정할 수 없으므로, 공식 공고 확인과 교육 콘텐츠 방향 검토를 나눴습니다.
- **맡긴 일** 제품기획 (product) - 신청 전 확인할 자격·요건·평가 기준과 확인 경로를 정리한다. / PM (pm) - 지원사업 검토 결과에 맞춘 한국어 교육 콘텐츠 후보와 우선 검증안을 제시한다.
- **결론** 신청 전 해당 연도 공식 공고에서 자격·서류·자부담·일정을 확인하고, 교육 콘텐츠는 방송에서 접한 표현을 직접 말하고 파비와 짧게 대화하는 경험부터 시험하는 안을 추천합니다.

### 아리랑TV 협업 AI 굿즈 판매

- **맡긴 일** 마케팅 (marketing) - AI 굿즈 판매를 위한 기능, 셀링 포인트, 판매 흐름의 우선순위를 제안한다.
- **결론** 앱의 일정 알림을 먼저 검증한 뒤 반복 사용이 확인되면 로봇 연계를 검토하고, ‘팬의 일정을 챙기는 파비’를 셀링 포인트로 제안하되 권리나 파트너 조건이 확인되지 않은 혜택은 판매 약속에서 제외합니다.

## 질문과 답

### 정부지원사업에 등록하려면 무엇이 필요한가?

- 현재 자료만으로는 신청 자격을 확정할 수 없다. 지원 요건 확인을 콘텐츠 기획보다 먼저 진행하기로 했으며[e-grant-ask], 신청 전에는 해당 연도 공식 공고 원문에서 신청 주체·사업 목적·제출 서류·자부담·일정을 대조하는 것을 추천한다. ([신청 전 확인할 자격·요건·평가 기준과 확인 경로를 정리한다.](grant-requirements.md))

### 지원사업 요건에 맞춰 외국인 K-pop 팬 대상 한국어 교육 콘텐츠를 어떻게 발전시킬까?

- tv파비를 활용한 ‘방송에서 접한 표현을 한국어로 말해 보고 파비와 짧게 대화하기’를 우선 후보로 추천한다. tv파비 활용과 한국어 교육은 기획 방향이지만[e-fixed-concept], 방송 연계 대화는 아직 제안이다[e-fan-concept]. 실제 방송 클립·원곡 가사·아티스트 음성 없이도 학습 경험을 먼저 시험한다. ([지원사업 검토 결과에 맞춘 한국어 교육 콘텐츠 후보와 우선 검증안을 제시한다.](grant-concept.md))

### 아리랑TV 협업 AI 굿즈인 파비를 많이 팔려면 앱·로봇에 어떤 기능을 더하고, 무엇을 셀링 포인트로 어떻게 팔아야 할까?

- 매니저형 일정 알림을 앱에서 먼저 검증하고, 반복 사용이 확인되면 로봇 연계를 검토하는 안을 추천한다. 매니저 방향은 선택됐지만 구체 동작은 미정이며[e-manager], 앱 선검증·실물 확장은 선행 문서의 제안이다[e-app-first]. ([AI 굿즈 판매를 위한 기능, 셀링 포인트, 판매 흐름의 우선순위를 제안한다.](goods-strategy.md))
