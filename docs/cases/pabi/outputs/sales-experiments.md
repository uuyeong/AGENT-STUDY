# 파비 굿즈 구매·구독 검증 실험표

## 핵심 요약

- 제안: 판매 메시지, 실물 수요, 월 구독 의향을 별도 실험으로 측정한다. 앱 선행은 기존 제안이며 구현 완료를 뜻하지 않는다[goods-app-first].
- 봉제 인형 5만 원·피규어 15만 원·월 1만 5천 원은 가격 후보이며 확정 판매가가 아니다[goods-price]. 모든 실험은 시제품 또는 가격 제시 테스트로 운영하고 결제 없이 행동을 비교한다.
- 답변지·음성·투표·방송 연동은 권리와 제공 조건 확인 전 판매 약속에서 제외한다[goods-exclusive][goods-voting][goods-live][partner-data]. 아래 통과 기준은 제안값이며 관찰 결과는 없다.

## 세부 항목

### 1. 판매 메시지: 앱 사용 이유와 굿즈 구매 이유 분리

- **실험** 동일한 앱 소개 화면에서 메시지 A/B를 무작위 노출한다. 협업 콘텐츠 제공을 암시하지 않는 시안 테스트다.
- **가설** 제안: 캐릭터 소장 메시지보다 관심 일정 알림·회차 후 기록의 반복 사용 메시지가 앱 체험 신청을 더 많이 만든다. 어느 메시지가 실물 구매 관심에도 영향을 주는지는 별도로 본다.
- **대상·표본** 제안: 대상 이용 가능성이 있는 신규 방문자, 군별 고유 방문자 200명 이상. 유입 경로별 배분을 기록한다.
- **비교군** A: 일정 알림·기록 중심. B: 캐릭터 소장·시제품 관심 중심. 화면 구성과 버튼 위치는 동일하게 둔다.
- **수집 방식** 각 메시지에서 ‘앱 체험 신청’과 ‘실물 시제품 상세 보기’를 별도 버튼으로 제공한다. 신청 연락처는 별도 동의를 받은 경우에만 수집하고 철회·삭제 경로를 안내한다.
- **지표·분모** 주지표: 앱 체험 신청 고유 인원 ÷ 해당 메시지를 본 고유 방문자. 보조지표: 실물 상세 보기 고유 인원 ÷ 해당 메시지를 본 고유 방문자. 두 행동을 합산하지 않는다.
- **기간** 제안: 14일 또는 군별 목표 표본 충족 시까지. 기간을 연장하면 연장 사유를 기록한다.
- **제안 통과 기준** 제안값: 한 메시지의 앱 체험 신청률이 다른 메시지보다 5%p 이상 높고, 군별 표본을 충족할 때 우선 메시지로 채택한다. 실물 상세 보기 차이는 별도 보고한다. 관찰 수치 없음.
- **후속 결정** 기준 충족 시 우세 메시지로 앱 체험 유입을 설계한다. 미충족 시 문구보다 실제 앱 과업의 수요를 먼저 확인한다. 클릭만으로 구매 의향이나 유료 반복 사용을 확정하지 않는다.

### 2. 실물 수요: 봉제 인형·피규어 시제품과 가격 후보

- **실험** 시제품 사진 또는 명확히 표시한 목업으로 SKU별 상세 화면을 테스트한다. 봉제 인형 5만 원, 피규어 15만 원을 각각 후보 가격으로 제시한다[goods-price].
- **가설** 제안: 가격을 본 뒤에도 실물 시제품 알림을 신청하는 행동이 앱만 이용하려는 선택과 구분되어 나타난다.
- **대상·표본** 제안: 실물 상세 화면에 진입한 고유 방문자, SKU별 200명 이상. 동일인이 두 SKU를 볼 수 있으므로 SKU 간 합계는 중복 제거해 보고한다.
- **비교군** 각 SKU 화면에서 ‘시제품 출시 알림 신청’과 ‘앱 체험만 신청’을 나란히 제시한다. 두 SKU는 형태와 후보 가격이 함께 달라 어느 차이가 원인인지는 판정하지 않는다.
- **수집 방식** 가격 표시 뒤 비구속적 출시 알림 신청을 받으며, 결제·선주문·재고 확보는 제공하지 않는다. 시제품 여부와 최종 가격·배송비·세금 미확정을 화면에 표시한다[goods-price]. 연락처 수집·삭제는 별도 동의와 철회 경로를 마련한다.
- **지표·분모** SKU별 주지표: 가격 확인 후 출시 알림을 신청한 고유 인원 ÷ 해당 SKU의 가격을 확인한 고유 인원. 보조지표: 같은 분모의 앱만 신청한 고유 인원 비율. 중복 선택자는 별도 집계한다.
- **기간** 제안: 14일 또는 SKU별 목표 표본 충족 시까지.
- **제안 통과 기준** 제안값: SKU별 출시 알림 신청률 10% 이상이며, 신청자의 절반 이상이 후속 시제품 안내 수신에 동의하면 해당 SKU의 견적·제작 검토로 넘긴다. 관찰 수치 없음.
- **후속 결정** 통과해도 구매 확정으로 해석하지 않는다. 원가·배송비·세금·최종 가격과 시제품 제작 가능성을 확인한 뒤 결제 기반 판매 실험 여부를 별도 결정한다[goods-price]. 미통과 SKU는 제작 범위를 줄이거나 보류한다.

### 3. 월 구독: 반복 사용 후 1만 5천 원 가격 제시

- **실험** 협업 자료 없는 앱 체험에서 일정 알림·회차 후 기록을 사용한 뒤, 월 1만 5천 원 후보 가격의 구독 시안을 제시한다[goods-price][goods-app-first]. 결제 기능은 열지 않는다.
- **가설** 제안: 재방문 경험이 있는 이용자가 가격을 확인하고 유료 출시 알림을 선택한다. 알림 선택은 실제 지불과 구분한다.
- **대상·표본** 제안: 앱 체험에 동의한 이용자 300명 이상. 가격 화면 노출군과 비노출군을 각 150명 이상으로 배정하되, 실제로 가격을 본 인원도 별도 기록한다.
- **비교군** A: 월 1만 5천 원 후보 가격과 포함 가능한 앱 기능만 표시. B: 같은 기능 설명과 무료 체험 지속 선택지만 표시. 답변지·음성·투표 혜택은 양쪽 모두 제외한다[goods-exclusive][goods-voting].
- **수집 방식** 체험 시작일과 주간 알림·기록 사용을 기록하고 2주차에 시안을 노출한다. A군은 ‘유료 출시 시 안내받기’, 양 군은 ‘무료 체험 계속하기’를 선택할 수 있다. 연락처·이용 기록의 수집 목적, 동의 철회와 삭제 방법을 안내한다. 일정 데이터 출처·정정 책임, 시간대, 알림 전달 가능성이 확인되어야 체험을 시작한다.
- **지표·분모** 반복 사용률: 2주차에 알림 확인 또는 기록 행동을 한 고유 인원 ÷ 체험을 시작한 고유 인원. 가격 관심률: 유료 출시 알림 선택 고유 인원 ÷ A군에서 가격 화면을 본 고유 인원. 배정군 대비 가격 화면 도달률도 보고해 선택 편향을 확인한다.
- **기간** 제안: 모집 2주, 이용자별 관찰 4주. 2주차 가격 제시 후에도 재방문을 관찰한다.
- **제안 통과 기준** 제안값: 체험 시작자 중 2주차 반복 사용률 25% 이상, A군 가격 확인자 중 유료 출시 알림 선택률 15% 이상을 모두 충족한다. 관찰 수치 없음.
- **후속 결정** 두 기준을 충족하면 제공 기능·운영 비용·가격 조건을 확정한 후 별도 결제 기반 파일럿을 검토한다. 알림 선택만으로 월 1만 5천 원의 실제 지불 의향이 검증됐다고 주장하지 않는다. 반복 사용이 낮으면 구독 실험을 확대하지 않고 앱 효용부터 수정한다.
