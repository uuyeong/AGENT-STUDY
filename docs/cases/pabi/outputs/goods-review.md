# 쇼케이팝 연계 AI 굿즈 제품 경험·판매 가설 검토

## 핵심 요약

- 회의에서 매니저 방향을 선택했지만 적용 사업과 구체 동작은 정하지 않았다.[e11] 판매 경험은 앱의 팬토크·알림을 먼저 검토하고 실물 확장을 후보로 두는 선행 제안이며, 출시 순서가 확정된 것은 아니다.[e10]
- 기기 구성·가격·구독료, 아티스트 소재 활용, 외부 구독 혜택은 모두 확인이 필요하다.[e12][e14][e15] 첫 검증은 권리와 구현 조건을 확인한 앱 경험에 한정하고, 반복 사용률과 유료 전환 의향을 분리해 판단한다.

## 세부 항목

### 앱 선행 경험: 팬토크·알림

- **경험·기능 후보** 우선 검증 후보. 팬이 앱에서 대화 소재를 선택하고 응답을 받거나 알림을 확인하는 경험을 비교한다. 입력·응답 범위와 알림 발생 조건은 설계 전 확인한다.
- **대상 사용자** 쇼케이팝 연계 상품에 관심을 보인 팬. 반복 방문 이유가 실제로 있는지는 미검증이다.
- **앱·실물 역할** 앱에서 경험을 검증한다. 실물 구매나 기기 연동을 성공 조건으로 두지 않는다.
- **자료상 근거** 판매 사업에서 앱 팬토크·알림을 먼저 검토하고 실물 확장을 후보로 둔 선행 제안이다.[e10] 구현 또는 출시 결정은 확인되지 않았다.
- **확인할 가설** 제안 기준: 동의한 체험자 중 7일 안에 2회 이상 자발적으로 재방문한 비율을 관찰한다. 분모는 첫 체험을 완료하고 측정에 동의한 사람, 관찰 기간은 첫 체험 후 7일이다. 재방문과 알림 해제·불편 신고를 함께 보고 경험을 유지·수정·중단한다. 기준값은 체험 전 정하고 관찰 결과와 구분해 기록한다.
- **보류 사항** 응답의 데이터 출처·갱신 주기, 알림 수신 동의·해제, 대화 기록 보관·삭제 방식, 응답 오류 시 안내와 재시도 범위를 정해야 한다. 첫 버전에서는 실제 아티스트와의 실시간 대화로 오인될 표현을 제외한다.

### 매니저 역할

- **경험·기능 후보** 선택된 방향을 기능으로 구체화할 후보. 일정 안내, 팬 활동 정리 등 가능한 역할을 사용자 장면별로 비교하되 특정 동작을 확정하지 않는다.
- **대상 사용자** 팬의 활동을 챙겨 주는 경험에 수요가 있는지 확인할 체험자. 사용 빈도와 대체 수단은 인터뷰에서 확인한다.
- **앱·실물 역할** 앱 화면에서 역할의 필요성을 먼저 검증할 수 있는지 검토한다. 기기 동작이나 운영자 개입 범위는 미정이다.
- **자료상 근거** 회의에서 매니저 방향을 선택했으나 적용 사업과 구체 동작은 특정하지 않았다.[e11]
- **확인할 가설** 제안: 역할별 모의 화면을 보여 주고 기존 알림·캘린더 대신 쓸 이유와 불필요한 개입을 조사한다. 역할을 하나로 좁힌 뒤 해당 동작의 입력, 성공 조건, 실패 안내를 정의하고 재방문 실험 여부를 결정한다.
- **보류 사항** 판매 사업에 이 결정을 적용할지, 일정·활동 데이터의 출처와 갱신 책임자가 누구인지 확인해야 한다. 확인 전에는 자동 일정 관리나 개인화 실행을 약속하지 않는다.

### 실물 굿즈·기기와 유료 구성

- **경험·기능 후보** 앱 경험이 유효할 때 실물 확장과 기기별 구성, 일회성 판매·구독 조합을 비교할 후보.
- **대상 사용자** 앱 체험 뒤 소장 가치 또는 기기 사용 가치를 느끼는 팬. 구매 의향과 실제 결제는 구분한다.
- **앱·실물 역할** 앱은 경험을 제공하고 실물은 소장·접근 수단이 될 수 있다. 연동 방식과 기기에서 처리할 기능은 정해지지 않았다.
- **자료상 근거** 실물 확장은 선행 제안이다.[e10] 기기별 가격과 구독료는 후보로 언급됐으며 구성과 정식 가격은 미정이다.[e12]
- **확인할 가설** 제안: 구성안별 설명을 동일 조건으로 제시해 선택 이유와 지불 의향을 조사한다. 분모는 각 안을 모두 본 응답자이며, 구매 의향을 판매 실적으로 해석하지 않는다. 원가·권리·지원 비용을 확인한 뒤 구성과 가격 실험 여부를 결정한다.
- **보류 사항** 기기 구현·공급, 앱 연동 실패 시 사용 가능 범위, 환불·고객지원, 정식 가격과 출시 일정은 미정이다. 검증 전에는 사전 판매나 구독 혜택을 확정하지 않는다.

### 아티스트 소재를 활용한 팬 참여

- **경험·기능 후보** 아티스트 답변지·음성 파일을 활용한 경험과 팬레터 코치·떼창 채점을 별개 후보로 비교한다. 실제 아티스트 응답이나 공식 채점으로 표현하지 않는다.
- **대상 사용자** 메시지 작성 또는 노래 참여를 원하는 팬. 어느 활동이 반복 사용을 만드는지는 미검증이다.
- **앱·실물 역할** 입력·결과 확인은 앱 후보로 두고 실물 적용은 검증 후 판단한다. 음성 처리 위치와 운영자 검수 범위는 정하지 않았다.
- **자료상 근거** 기존 콘셉트 문서가 답변지·음성 파일 활용을 제안했다.[e15] 팬레터 코치와 떼창 채점도 아이디어로 제시됐다.[e16]
- **확인할 가설** 제안: 권리가 확인된 예시 소재로만 각 경험의 이해도와 재사용 의향을 비교한다. 떼창 채점은 평가 기준과 오채점 시 안내·재시도 방법을 검증한 뒤 구현 여부를 결정한다.
- **보류 사항** 소재 사용 범위·기간·동의와 철회, 팬 입력물 및 음성의 수집·보관·삭제, 부적절한 출력의 검수·신고 절차가 확인되지 않았다. 확인 전에는 아티스트 음성 생성이나 채점 정확도를 약속하지 않는다.

### 외부 파트너 구독 혜택

- **경험·기능 후보** 스트리밍 또는 투표 파트너의 혜택을 구독과 묶는 판매 가설. 앱 기본 경험과 분리해 검토한다.
- **대상 사용자** 해당 외부 서비스를 이미 쓰거나 혜택에 관심이 있는 팬.
- **앱·실물 역할** 앱은 혜택 안내·확인 창구가 될 수 있으나 계정 연동과 혜택 지급 주체는 미정이다. 실물은 필수 요소로 두지 않는다.
- **자료상 근거** 스트리밍 또는 투표 파트너와 구독 혜택을 만드는 방안이 제안됐다.[e14] 협의 성사나 제공 권리는 확인되지 않았다.
- **확인할 가설** 제안: 파트너의 제공 가능 범위와 비용·운영 책임을 먼저 확인한다. 이후 혜택 없는 구성과 비교해 구독 선택률을 관찰할지 결정하며, 협의 전의 관심 응답을 전환 성과로 쓰지 않는다.
- **보류 사항** 파트너 계약, 혜택 조건·중단 시 처리, 계정 데이터 공유 동의·삭제, 가격과 구독 운영 방식은 모두 미정이다. 외부 합의 전에는 혜택을 판매 문구나 출시 범위에 포함하지 않는다.
