# K-pop 팬 활동 한국어 말하기 에피소드 샘플: 굿즈샵에서 응원봉 묻기

## 핵심 요약

- 초급 성인 해외 팬이 공연 전 가상의 굿즈샵에서 응원봉 재고를 묻고 수량을 말하는 4턴 자작 대화 시안이다. 팬 활동 상황극과 짧은 발화 복습은 검토 중인 후보이며 학습 효과는 확인되지 않았다. [edu-scope][edu-material]
- 녹음은 선택 사항으로 두고 인식 결과가 불확실하면 텍스트 선택으로 이어간다. 가사·방송 원본·권리 확인 없는 음성은 사용하지 않으며, 게시 전 교육 적합성과 음성·이미지 자산을 확인해야 한다. [rights]

## 에피소드 목표와 장면

대상은 한국어로 짧게 말해 보려는 초급 성인 해외 팬이다. 장면은 공연 전 가상의 굿즈샵에서 직원에게 응원봉이 있는지 묻고 필요한 수량을 말하는 연습이다. 실제 공연, 아티스트, 판매처 또는 재고를 나타내지 않는 자작 상황극이다. 팬 활동을 발화 연습에 연결하는 방향은 기획 후보이며 대상과 우선 난이도는 검증 전이다. [edu-research][edu-scope][edu-material]

훈련 목표(제안): 학습자가 ‘응원봉 있나요?’로 재고를 묻고, 직원의 수량 질문에 ‘한 개 주세요.’로 답한다.

## 4턴 자작 대화

1. 직원: ‘안녕하세요. 무엇을 찾으세요?’ / ‘Hello. What are you looking for?’
2. 학습자: ‘응원봉 있나요?’ / ‘Do you have light sticks?’
3. 직원: ‘네, 있습니다. 몇 개 필요하세요?’ / ‘Yes, we do. How many do you need?’
4. 학습자: ‘한 개 주세요.’ / ‘One, please.’

직원의 ‘있습니다’는 연습용 대사일 뿐 실제 재고 안내가 아니다.

## 화면 문구와 피드백

첫 발화 화면의 제목은 ‘응원봉이 있는지 물어보세요’, 안내는 ‘직원에게 짧게 말해 보세요’, 버튼은 ‘녹음해서 말하기(선택)’와 ‘문장 골라 보기’로 제안한다. 예시 문장을 먼저 보여 줄 경우 그대로 따라 읽을 수 있음을 학습 방식에 반영해 검토한다.

- 응답 예시 A: ‘응원봉 있나요?’ → ‘좋아요. 있는지 물어봤어요. 이제 수량 질문을 들어 보세요.’ 다음 행동: 직원의 3턴으로 이동.
- 응답 예시 B: ‘응원봉 한 개 주세요.’ → ‘필요한 수량은 말했어요. 이번 목표는 먼저 있는지 묻는 거예요. “응원봉 있나요?”라고 다시 말하거나 골라 보세요.’ 다음 행동: 같은 턴 재시도.
- 4턴에서 ‘한 개 주세요.’라고 답하면 ‘좋아요. 필요한 수량을 말했어요.’를 표시한다. 답을 고르지 못한 경우에는 ‘한 개’를 눌러 완성할 수 있게 한다.

빈 상태 문구: ‘아직 답을 고르지 않았어요. 말하거나 문장을 골라 보세요.’ 실패·불확실 상태 문구: ‘말을 정확히 확인하지 못했어요. 다시 녹음하거나 문장을 골라 계속할 수 있어요.’ 이는 기능 동작이 확인됐다는 뜻이 아닌 화면 시안이다.

## 녹음 선택과 대체 경로

녹음은 선택 사항이다. 녹음을 원하지 않거나 사용할 수 없으면 처음부터 문장 선택으로 4턴을 마칠 수 있게 제안한다. 음성 인식 결과가 불확실할 때는 정답·오답으로 단정하지 않고 다시 녹음, 직접 확인 가능한 문장 선택, 다음 단계로 이어지는 경로를 제시한다. 인식 정확도와 실제 구현 가능 여부는 확인되지 않았다. [edu-research]

## 제작 자료·검수

필요한 원본은 자작 한영 대사, 수정 가능한 화면 문구 파일, 권리와 사용 범위를 확인한 배경 이미지 또는 직접 제작한 배경, 사용 허락 범위를 확인한 기본 안내 음성이다. 가사, 방송 원본, 권리 확인 없는 음성은 사용하지 않는다. 실제 아티스트의 발화나 참여처럼 표현하지 않는다. 저작물 인용에 ‘30초’ 같은 일률적 허용 기준을 적용하지 않으며, 외부 소재는 용도별 권리 확인 전까지 보류한다. [rights]

콘텐츠 제작자는 A·B 응답의 피드백과 재시도, 녹음 미선택 경로, 불확실 상태 문구를 화면 시안에서 확인한다. 한국어 교육 검토자는 초급 성인이 재고 질문과 수량 요청을 구별할 수 있는지, ‘있나요?’와 ‘한 개 주세요.’의 난이도 및 영어 풀이가 적절한지 판단한다. 실제 학습 효과는 확인되지 않았으므로 대상 학습자 검토 결과에 따라 표현과 난이도를 조정한다. [edu-research] 촬영·편집·외부 게시는 진행하지 않았으며, 외부 게시 여부는 오너의 승인 사항이다.
