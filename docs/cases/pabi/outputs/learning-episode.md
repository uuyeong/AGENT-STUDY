# 팬 굿즈샵에서 한국어로 물어보기 — 말하기 에피소드 시안

대상은 초급 성인 해외 K-pop 팬이다. 가상의 굿즈샵에서 원하는 물건의 위치를 묻는 장면으로 구성한다. 팬 활동 상황극과 짧은 발화 복습은 기존 기획의 후보이며, 학습 효과는 확인 전이다. [edu-material] [edu-scope]

훈련 목표: “○○은 어디에 있어요?”로 위치를 묻고, 안내를 들은 뒤 “감사합니다”로 대화를 마친다. 등장인물은 가상의 손님과 직원이며, 실존 아티스트를 연기하거나 대변하지 않는다.

4턴 자작 대화

1. 직원: “어서 오세요. 무엇을 찾으세요?” / “Welcome. What are you looking for?”
2. 학습자: “포토카드는 어디에 있어요?” / “Where are the photo cards?”
3. 직원: “저쪽 선반에 있어요.” / “They’re on that shelf over there.”
4. 학습자: “감사합니다.” / “Thank you.”

2턴 응답 예시와 피드백

- 목표 응답: “포토카드는 어디에 있어요?” → 피드백: “좋아요. 물건 이름 뒤에 ‘어디에 있어요?’를 붙여 위치를 물었어요.”
- 의미는 통하지만 연습할 표현이 빠진 응답: “포토카드 어디?” → 피드백: “뜻은 전해질 수 있어요. 직원에게 묻는 문장으로 ‘포토카드는 어디에 있어요?’를 다시 말해 보세요.”

화면과 다음 행동

- 시작: “굿즈샵에서 포토카드를 찾아보세요.” 버튼: “대화 시작”
- 학습자 차례: “직원에게 위치를 물어보세요.” 예시 문장 보기와 입력 방식을 함께 제공한다. 녹음은 선택이며, 녹음하지 않아도 문장을 읽고 따라 말하거나 직접 입력해 진행할 수 있도록 설계한다.
- 빈 상태: “아직 답을 입력하지 않았어요. 예시를 보고 말하거나 문장을 입력해 보세요.” 버튼: “예시 보기” / “문장 입력”
- 음성 인식 결과가 불확실한 상태: “말한 내용을 정확히 확인하지 못했어요. 다시 녹음하거나, 말한 문장을 직접 입력해 주세요.” 버튼: “다시 녹음” / “직접 입력” 인식 결과만으로 발음의 정오를 단정하지 않는다.
- 마무리: “이제 안내를 들었어요. ‘감사합니다’로 답해 보세요.” 완료 후에는 목표 문장을 한 번 더 말하거나 읽는 재시도를 제안한다.

제작·검토 메모: 대사와 화면 문구는 이 시안의 자작 예시다. 가사, 방송 원본, 서명 없는 음성은 사용하지 않는다. 실존 아티스트 소재와 외부 저작물은 용도별 권리 확인 전까지 넣지 않는다. [rights] 음성 인식·발화 평가·기기 연동은 이번 의뢰에서 확인되지 않았으므로, 구현 전 입력 방식과 실패 시 대체 경로를 검증해야 한다. [edu-platform] 교육 검토자는 초급 학습자에게 질문 표현과 피드백의 난이도가 적절한지 확인하고, QA는 빈 입력과 인식 불확실 상태에서 문장 입력으로 계속 진행할 수 있는지 재현한다.
