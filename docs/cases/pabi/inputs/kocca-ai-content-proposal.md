## 3. 문제·시장 환경 (아이디어를 고른 계기)

### 3-1. 채점 항목이 요구하는 방향 [공고문]

| 채점 항목 | 요구하는 것 | 아이디어에 주는 방향 |
| --- | --- | --- |
| AI기술 융합성 (20점, 최대) | AI 기술의 실효성, 콘텐츠 융합기술 고도화 | 범용 AI를 그대로 쓰지 않고, 우리 파이프라인으로 고도화한 기술이 중심이어야 함 |
| 사업 이해도 (15점) | 글로벌 선도형 사업 목적의 적합성 | 해외 이용자를 대상으로 하는 문화콘텐츠 |
| 경쟁력 (10~15점) | IP·기술·파트너십 비교 우위 | 쇼케이팝 협업, tv파비 실물 |
| 시장성 (10~13점) | 수요·매출·수출 규모 | 근거 있는 시장 규모 산출 |
| 투자유치 (10점) | IR 피칭 계획 | 확장 가능한 수익 구조 |
| 글로벌 경쟁력 (10점) | AI 콘텐츠 품질의 글로벌 경쟁력 | 해외 검증이 가능한 구조 |
- **평가 방향의 변화:** 2024·2025 서면평가에는 "유통 구체성"과 "대중성(상업성)" 항목이 있었어요. 2026에는 이 항목이 빠지고 **"AI기술 융합성(20)"과 "글로벌 경쟁력(10)"**이 새로 들어왔어요. [공고문·평가기준 문서]

### 3-2. 선정작 공통점에서 나온 방향 [선정결과 + 자체 정리]

- **교육·학습형**은 콘텐츠 경험으로 포장했을 때 선정 사례가 있어요 (아티젠스페이스 2년 연속).
- **K-pop·팬 인터랙션**이 2026에 선정됐어요 (지로, 올림플래닛).
- **대화형 AI** 콘텐츠가 꾸준히 선정됐어요 (일루니, 툰스퀘어, 이제이비전).
- **외부 파트너·IP 활용**도 선정됐어요 (뉴튠, 툰스퀘어, 벤타엑스).

**4-1-1. 한 줄 컨셉**

쇼케이팝을 보는 시간이 한국어를 익히는 시간이 되도록, 파비가 옆에서 같이 보며 대화하는 K-pop 팬 콘텐츠

**4-1-2. 아이디어 상세 설명**

- **무엇을 하는 서비스인가**
    - 해외 팬은 쇼케이팝을 보면서도 아티스트의 한국어를 이해하지 못하고, 말해 볼 상대도 없어요.
    - 파비는 사용자가 방송을 보는 동안 소리를 듣고, 그 자리에서 리액션하며 방금 나온 한국어 표현을 짚어 줘요.
    - 방송이 끝나면 그 회차에 나온 아티스트와 곡을 소재로 회화를 이어가요.
- **사용 장면**
    1. 월요일, 사용자가 TV나 틱톡으로 쇼케이팝을 켜요.
    2. 파비가 방송 소리를 듣고 "지금 1위 후보 나왔다!"처럼 반응해요. 무대 중에는 조용히 있어요.
    3. MC 멘트나 무대 사이 시간에 아티스트의 한국어 멘트를 짚어요: "방금 '감사합니다, 여러분'이라고 했지? 따라 해 볼래?"
    4. 방송이 끝나면 회차 회화로 이어가요: "오늘 1위 곡 어땠어? 한국어로 말해 볼까?"
    5. 실시간 투표 시간에는 응원·투표 표현을 연습해요.

### 4-2. 아이디어 C: 교포 아이의 한국어 친구 파비

    - 부모는 앱으로 아이가 어떤 말을 했는지 확인하고, 가족이 함께하는 미션을 받아요.
- **사용 장면**
    1. 하교 후 아이가 파비에게 "오늘 학교에서 뭐 했는지" 한국어로 이야기해요.
    2. 파비가 아이 수준에 맞춰 대답하고, 새 표현을 하나 알려줘요.
    3. 저녁에 부모 앱에 "오늘 한국어로 말한 시간, 새로 쓴 표현"이 도착해요.

### 4-4. 아이디어 E: 한국어로 키우는 파비

**4-4-1. 한 줄 컨셉**

**4-4-2. 아이디어 상세 설명**

- **무엇을 하는 서비스인가**
    - 혼자 공부하는 학습자는 꾸준히 하기 어렵고, 배운 표현을 써 볼 곳도 없어요.
    - 이 아이디어에서는 파비가 "배우는 사람"이 되고, 사용자가 "가르치는 사람"이 돼요.
    - 사용자가 가르친 표현을 파비가 기억했다가 대화에서 쓰고, 다시 물어봐요.
    - 점수·레벨 같은 게임 요소 없이 음성 대화로만 진행해요.
- **사용 장면**
    1. 파비가 묻기: "어제 방송에서 MC가 '대박'이라고 했는데, 무슨 뜻이야?"
    2. 사용자가 뜻과 쓰는 상황을 설명하면, 파비가 기억해요.
    3. 다음 날 파비의 오늘 한마디: "오늘 배운 말! 이 노래 대박이다~"
    4. 며칠 뒤 퀴즈: "퀴즈야! 내가 한 말에서 틀린 곳 찾아봐." → 사용자가 답하면 정답 문장을 바로 들려줘요.
- **핵심 기능**

| 기능 | 설명 |
| --- | --- |
| 파비에게 가르치기 | 사용자가 가르친 표현을 파비가 기억하고 대화에 사용 |
| 파비의 질문 | 방송(A)이나 일상에서 들은 말을 파비가 먼저 물어봐요 |

| 틀린 곳 찾기 퀴즈 | "퀴즈야!"라고 먼저 알린 뒤 틀린 문장을 내고, 답과 상관없이 정답 문장을 바로 들려줘요 |
- **기기와 앱의 역할**
    - **파비 기기:** 가르치기·질문·한마디·퀴즈 음성 대화
    - **앱:** 가르친 표현 목록
- **tv파비·쇼케이팝과의 연결**
    - Dasoni 장기 기억 자산을 학습 기록으로 써요.

**채택 방식:** AI는 가사를 출력·저장·학습하지 않아요. 가사 출력 차단 가드레일을 두고, 일반 표현만 해설하고, 가사는 사용자가 자기 음악앱에서 확인해요. 최종 확정 전에 저작권 자문이 필요해요.
