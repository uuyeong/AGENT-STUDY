# 파비 두 사업 검토

한국어 교육형 정부지원사업과 아리랑TV 협업 판매용 AI 굿즈는 별도 사업이다. 두 사업의 목표, 사용자, 검증 기준, 출시 전제와 산출물을 구분한다. 공유 가능한 제품 자산은 출처와 적용 범위를 설명한다. 회의 결정의 적용 사업이 불명확하면 귀속 확인 사항으로 남긴다.

한국어 교육 사업은 K-pop 팬의 구체적 발화 문제를 해결하는 참여형 콘텐츠와 실험을 설계한다. 판매 사업은 구매 이유, 반복 사용, 지불 의향, 앱·기기별 최소 기능을 판단한다. 실험 수치와 가격은 제안으로 표시하고 출시 판단을 위한 근거를 수집한다. 내부 검토용으로 작성하며 외부 배포와 협의 확정은 별도 판단이다.
