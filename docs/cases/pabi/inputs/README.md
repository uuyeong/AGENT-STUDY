## 실제 Hermes 실행 입력

| 파일 | 역할 |
| --- | --- |
| [의뢰서](brief.md) | 목표, 두 사업의 적용 범위, 산출물 활용 맥락 |
| [트랙·산출물 명세](job.toml) | 교육·판매 트랙, 산출물 6개의 독자·목표·완료 기준·선행 관계 |
| [가공 근거](evidence.toml) | 위 자료와 확인한 공식 출처에서 추린 근거 21개, 상태와 출처 |
| [실행 입력 스냅샷](run-inputs.json) | 실행기가 읽은 의뢰서·트랙·산출물·근거의 JSON 기록 |

Hermes는 실행 입력의 구조화 근거를 모델에 전달했다. 참고 자료는 해당 근거의 출처를 대조하는 데 사용한다. 작성 역할별 입력은 PM 배정과 선행 산출물에 따라 달라진다. [근거 분류와 역할 배정](../execution/plan.json)
