# 아이디어 구체화

## 1. 개요

### 1.1 한 줄 컨셉

> **"매주 쇼케이팝을 같이 보고, 그 회차로 한국어를 배우고, 내가 만든 한국어 노래로 마무리하는 K-pop 팬 전용 AI 친구, 파비"**
> 

### 1.2 서비스 구성

| 구성 | 역할 |
| --- | --- |
| **파비 (기기)** | 방송을 같이 보고, 대화하고, 먼저 말을 거는 음성 AI 친구 |
| **파비 앱** | 일정·학습 기록·노래 보관함·목소리 선택·설정 |
| **아리랑 쇼케이팝 협업** | 아티스트 질문 답변지와 아티스트 음성 파일 제공 → 파비만 가진 독점 콘텐츠 |

### 1.3 아리랑 제공 데이터 활용

| 제공 데이터 | 활용 기능 |
| --- | --- |
| 아티스트 질문 답변지 | '파비만 아는 이야기' 대화, 아티스트 카드, 아티스트 추천 한국어 단어 |
| 아티스트 음성 파일 | 아티스트 목소리 선택(앱), 알람·인사 멘트, 방송 후 해금 음성 메시지 |

---

## 2. 핵심 구조: 쇼케이팝 주간 루프

쇼케이팝 생방송(매주 월요일 18:00~19:10 KST)을 중심으로 일주일 동안 파비와 함께하는 흐름입니다.

| 시점 | 파비가 하는 일 | 관련 기능 |
| --- | --- | --- |
| 방송 2~3일 전 | "이번 주 쇼케이팝에 ○○ 나온대! 방송 시간 알려줄까?" | 먼저 말 걸기, 일정 |
| 방송 직전 | 사용자 시간대에 맞춘 알림, 출연 아티스트 관련 예습 단어 3개 | 먼저 말 걸기 |
| 방송 중 | 파비가 방송을 직접 보면서 무대 중엔 조용히, 멘트 사이에 리액션과 표현 해설 | 같이 보기 |
| 방송 직후 | 회차 내용으로 대화하고, 아티스트 답변·음성 메시지 해금 | 회차 회화, 파비만 아는 이야기 |
| 주중 | 팬 현장 롤플레이, K-pop 표현 공부, 애매한 한국어 스페셜 | 현장 회화, 가사로 공부, 스페셜 단어 |
| 주말 | 이번 주 배운 단어로 '오늘의 노래 만들기' → 앱에 보관하고 공유 | 노래 만들기 |

매주 방송이 새로 나오기 때문에 콘텐츠가 끊기지 않고, 사용자가 파비에게 다시 돌아올 이유도 매주 생깁니다.

## 3. 기능 구성

### 3.1 방송 같이 보기

**개념**

- 파비가 쇼케이팝 공식 라이브 송출을 **내부에서 직접 스트리밍으로 받아** 사용자와 함께 실시간으로 시청함
- 큐시트나 대본 없이 파비가 방송을 보고 들으며 스스로 상황을 판단함

**사용자 경험**

- 사용자: "파비야, 쇼케이팝 같이 보자!"
- 파비가 방송 송출을 받기 시작함. 사용자는 TV·틱톡·유튜브 등 원하는 화면으로 시청함
- 무대 중에는 조용히 함께 감상함
- 무대가 끝나고 MC 멘트가 나오는 사이에 짧게 반응함
    - "방금 MC가 '컴백'이라고 했지? 다시 돌아왔다는 뜻이야!"
    - "'떼창'은 관객이 다 같이 노래 부르는 거야. 이따 우리도 해볼까?"
- 리액션은 회차당 일정 횟수 이하로 제한해 시청을 방해하지 않음

**파비가 방송을 이해하는 방식**

| 단계 | 내용 |
| --- | --- |
| ① 방송 수신 | 쇼케이팝 공식 라이브 송출을 파비 서버가 실시간으로 받음 |
| ② 구간 판별 | 음악(무대)과 말소리(MC 멘트, 인터뷰)를 구분해 무대 중 발화를 금지함 |
| ③ 멘트 인식 | MC·아티스트의 말을 실시간 음성인식으로 텍스트화 |
| ④ 화면 이해 | 화면 속 자막·출연자를 인식해 지금 누구 무대인지 파악 |
| ⑤ 시점 맞추기 | 사용자의 TV·앱 화면과 파비 스트림 사이 지연을 맞추기 위해, 방 안에서 들리는 방송 소리와 파비가 받은 스트림 소리를 비교해 시점을 정렬함 |
| ⑥ 리액션 생성 | 파비 페르소나에 맞춰 리액션과 학습 포인트(단어·표현 해설)를 생성 |

**방송 후 남는 것**

- 그 회차에서 나온 표현 5개가 자동으로 '이번 주 표현'으로 단어장에 저장되어, 회차 회화(3.2)로 이어짐

### 3.2 회차 기반 회화

- 같이 보기에서 인식한 회차 내용(출연 아티스트, 멘트, 무대 순서)으로 3~5턴짜리 **대화 에피소드**를 생성
    - 파비: "오늘 ○○ 무대 봤어? 어떤 부분이 제일 좋았어?"
    - 사용자 답변 → 파비가 자연스러운 표현으로 고쳐 주고, 더 풍부한 표현을 제안
- 회차별 에피소드를 아카이브해, 지난 방송으로도 다시 대화 가능
- 방송 직후 해금되는 아티스트 답변(3.8)을 대화 소재로 함께 사용

### 3.3 팬 현장 회화 (롤플레이)

실제 K-pop 팬 활동 상황을 가정한 말하기 연습입니다.

| 상황 | 연습 표현 | 파비의 역할 |
| --- | --- | --- |
| 팬사인회 | 자기소개, "○○에서 왔어요", 짧은 응원 메시지 | 가상의 아티스트 역 |
| 콘서트 | 입장·좌석 안내, 응원 구호, 옆자리 팬과 대화 | 스태프, 옆자리 팬 |
| 굿즈샵 | 가격·재고 묻기, 결제, 교환 요청 | 점원 |
| 쇼케이팝 방청 | 현장 대기, 안내 듣고 대답하기 | 방송 스태프 |
- 난이도는 3단계(입문, 일상, 자유 대화)
- 롤플레이가 끝나면 "오늘 잘한 표현 / 다음에 써볼 표현"을 피드백

### 3.4 K-pop으로 공부 (저작권 안전 설계)

**설계 원칙: 가사를 보여주거나 들려주지 않는다.** 가사 문장을 저장·출력·낭독하지 않고, K-pop에서 자주 쓰이는 **단어·문법·줄임말·발음 규칙**만 가르칩니다.

| 원칙 | 구체적인 방식 |
| --- | --- |
| 가사 원문 미사용 | 가사 문장을 DB에 저장하지 않고, 화면이나 음성으로 출력하지 않음 |
| 단어 단위로만 연결 | 곡과는 "이 노래에 '설레다'라는 단어가 나와"처럼 **곡 제목과 단어 하나** 수준으로만 연결 |
| 예문은 파비가 직접 작성 | 문법·표현 예문은 모두 파비가 새로 만든 문장 (예: '-고 싶어' → "나 너랑 쇼케이팝 보고 싶어") |
| 발음 연습도 자작 문장 | 연음·받침 같은 발음 규칙은 같은 규칙이 들어간 파비 자작 문장으로 연습 |
| 원곡 감상은 공식 플랫폼으로 | 가사를 확인하거나 노래를 듣고 싶으면 공식 음원·영상 플랫폼으로 연결 |
| 사용자가 가사를 말해도 반복하지 않음 | 사용자가 가사 구절을 말하면 그 안의 단어만 골라 설명하고, 구절 전체는 되풀이하지 않음 |

**학습 콘텐츠 구성**

| 유형 | 예시 |
| --- | --- |
| K-pop 빈출 단어 | 설레다, 그립다, 눈부시다, 영원히 |
| 팬덤·방송 용어 | 컴백, 음방, 직캠, 떼창, 응원법, 막내, 센터 |
| 줄임말·신조어 | 최애, 입덕, 덕질, 컴백 무대 '찢었다' |
| 문법 패턴 | -고 싶어, -지 마, -(으)ㄹ게, -잖아 |
| 발음 규칙 | 연음(사랑해요 → [사랑해요]), 받침 발음, 된소리 |

**진행 방식**

- 단어 소개 → 뜻을 상황으로 설명 → 파비 자작 예문 → 따라 말하기 → 발음 피드백

### 3.5 애매한 한국어 스페셜

외국어로 한 단어로 옮기기 어려운 한국어 감정·감각 표현을 '스페셜 단어'로 소개합니다.

**스페셜 단어 후보**

- 아련하다, 애틋하다, 뭉클하다, 짠하다, 서운하다, 설레다
- 싱숭생숭하다, 몽글몽글하다, 포근하다, 올망졸망하다, 아기자기하다
- 정, 눈치

**단어 하나의 구성**

| 순서 | 내용 | 예시 (아련하다) |
| --- | --- | --- |
| ① 상황으로 설명 | 뜻을 장면으로 보여줌 | "비 오는 날 옛날 사진을 보면 드는, 멀고 흐릿하지만 마음이 찡한 느낌" |
| ② 비슷한 단어 비교 | 미묘한 차이 | 아련하다 vs 그립다 vs 아쉽다 |
| ③ 쓰이는 맥락 | K-pop·드라마에서 쓰이는 장면 | 이별 노래의 분위기, 회상 장면 |
| ④ 사용자에게 되묻기 | 사용자 언어로는 어떻게 표현하는지 | "너희 나라 말로는 이 느낌을 뭐라고 해?" |
- 아리랑 답변지의 "외국 팬에게 알려주고 싶은 한국어 단어" 답변은 **아티스트 추천 스페셜 단어**로 운영
    - 예: "이번 주 스페셜 단어는 ○○가 골랐어!"

### 3.6 오늘의 노래 만들기

스페셜 단어로 사용자와 파비가 함께 한국어 가사를 쓰고, AI로 노래를 만들어 주는 기능입니다.

| 단계 | 내용 |
| --- | --- |
| ① 단어 고르기 | 이번 주 스페셜 단어 중 1~2개 선택 |
| ② 가사 함께 쓰기 | 사용자가 자기 언어로 감정·장면을 말하면 파비가 한국어 가사로 다듬음. 어색한 표현은 이유와 함께 고쳐 줌 (가사 2~4줄) |
| ③ 분위기 고르기 | 발라드, 댄스, 시티팝, 어쿠스틱 등 |
| ④ 노래 생성 | AI가 30초~1분 길이의 노래를 생성 |
| ⑤ 듣고 복습 | 파비가 노래를 틀어 주고, 가사 속 단어와 표현을 다시 짚어 줌 |
| ⑥ 보관·공유 | 앱 '내 노래 보관함'에 저장하고 숏폼으로 공유. AI 생성물 표시는 자동으로 삽입됨 |

**대화 예시**

> 파비: 이번 주 단어 '아련하다'로 노래 만들어 볼까? 언제 이런 느낌이 들어?
> 
> 
> 사용자: When I remember my first concert.
> 
> 파비: 좋다! 그럼 이렇게 써 볼까? "처음 본 무대가 아련하게 떠올라" 어때?
> 
- 가사는 사용자와 파비가 새로 만든 문장만 쓰고, 기존 곡의 가사나 멜로디는 사용하지 않음

### 3.7 오늘의 K-pop 일정

- 관심 아티스트의 일정을 사용자의 **현지 시간으로 바꿔서** 알려줌
    - "오늘 한국 시간 오후 6시에 ○○의 새 앨범이 나와! 너희 시간으로는 새벽 4시야. 알람 맞춰줄까?"
- 다루는 일정
    - 앨범·음원 발매
    - 음악방송 출연 (쇼케이팝 우선)
    - 콘서트·팬미팅·티켓 오픈
    - 생일·데뷔 기념일
    - 공식 라이브 예고
- 해외 팬은 한국 시간 일정을 매번 직접 환산해야 하므로, **시간대 자동 변환**이 이 기능의 핵심 가치
    - 예: 쇼케이팝 18:00 KST = 뉴욕 04:00 · LA 01:00 · 파리 10:00 · 자카르타 16:00 (11월, 서머타임 종료 후 기준)

### 3.8 파비가 먼저 말 걸기

**발화 유형**

| 유형 | 예시 |
| --- | --- |
| 알람 | "일어나! 오늘의 단어는 '설레다'야" (아티스트 목소리 알람 선택 가능) |
| 일정 알림 | "○○가 1시간 뒤에 쇼케이팝에 나와. 같이 볼래?" |
| 복습 알림 | "3일 전에 배운 '아련하다' 기억나? 한 번 써 볼까?" |
| 해금 알림 | "이번 주 쇼케이팝 아티스트 답변이 열렸어!" |
| 안부 | "오늘 하루 어땠어? 한국어로 말해 볼래?" |

**수집할 데이터**

| 분류 | 데이터 | 용도 | 수집 방법 |
| --- | --- | --- | --- |
| 사용자 설정 | 관심 아티스트, 거주 시간대, 기상 시간, 방해 금지 시간, 알림 빈도 상한 | 누구 일정을, 언제, 얼마나 자주 말할지 결정 | 앱 온보딩·설정 (사용자 동의) |
| 일정 데이터 | 발매 일시, 방송 출연, 공연·티켓 오픈, 생일·기념일 | 일정 알림 내용 | 쇼케이팝 출연 라인업, 소속사 공식 공지, 공식 SNS, 음원 발매 정보. 수집 후 운영자 검수 |
| 학습 데이터 | 배운 단어, 틀린 표현, 마지막 복습 날짜 | 복습 알림 시점 계산 (간격 반복) | 대화 기록에서 자동 추출 |
| 반응 데이터 | 알림에 답했는지, 무시했는지, 주로 답하는 시간대 | 알림 빈도·시간 자동 조정 | 기기·앱 사용 기록 |
| 기기 상태 | 최근 음성 감지 여부, 볼륨, 충전 상태 | 사용자가 없을 때는 말 걸지 않기 | 기기 상태 정보 |

### 3.9 파비만 아는 이야기 (아리랑 아티스트 답변지)

**운영 방식**

| 단계 | 내용 |
| --- | --- |
| ① | 쇼케이팝 출연이 확정된 아티스트에게 아리랑을 통해 질문지 전달 |
| ② | 아리랑으로부터 답변지(텍스트·음성)를 받아 파비 지식 DB에 등록 |
| ③ | **회차 방송이 끝나면 해금** → 방송을 볼 이유가 생김 |
| ④ | 파비와 대화할 때 해당 아티스트 이야기가 나오면 답변을 근거로 대답 |
| ⑤ | 앱에 '아티스트 카드'로 수집 |

**대화 예시**

> 사용자: ○○는 무대 전에 뭐 해?
> 
> 
> 파비: 이건 나만 아는 건데… ○○는 무대 올라가기 전에 꼭 멤버들이랑 손을 모으고 구호를 외친대!
> 

**질문지 예시 (대략)**

| 분류 | 질문 |
| --- | --- |
| 한국어 | 외국 팬에게 꼭 알려주고 싶은 한국어 단어 하나와 그 이유 / 멤버끼리만 쓰는 말이나 유행어 / 고향 사투리 한마디 |
| 이번 활동 | 이번 활동곡에서 가장 신경 쓴 부분 / 이번 무대에서 꼭 봐 줬으면 하는 장면 |
| 무대 비하인드 | 무대 직전 루틴 / 쇼케이팝 대기실 에피소드 |
| 팬 | 팬이 한국어로 말해 줘서 감동했던 순간 / 팬사인회에서 들으면 기분 좋은 말 |
| 일상 | 요즘 빠져 있는 한국 음식 / 아침에 일어나서 제일 먼저 하는 일 |
| 파비 전용 | 파비 사용자에게 보내는 한마디 / 알람·응원 멘트 녹음 |
- 답변은 가사 인용 없이 에피소드와 의미 중심으로 받음
- 사생활에 관한 질문은 넣지 않음

### 3.10 아티스트 목소리 선택 (앱)

아리랑으로부터 받은 아티스트 음성 파일로 파비의 목소리를 고를 수 있게 합니다.

| 단계 | 방식 | 내용 |
| --- | --- | --- |
| 1단계 | 녹음 음성 재생 | 아티스트가 직접 녹음한 알람·인사·응원 멘트, 방송 후 음성 메시지 |
| 2단계 | 아티스트 목소리로 대화 | 받은 음성 데이터로 파비의 대화 목소리를 아티스트 목소리로 전환 (아티스트·소속사 동의 범위 안에서) |
- 기본 목소리는 **파비 고유 목소리**이며, 아티스트 목소리는 앱에서 선택하는 보이스팩으로 제공
- 아티스트 목소리로 말할 때는 AI 합성 음성이라는 안내를 함께 표시
