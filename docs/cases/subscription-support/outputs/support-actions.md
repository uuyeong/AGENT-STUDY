# 정기배송 문의 예방·이관 개선표

## 핵심 요약

- 표본 4건 중 배송 일정·변경 문의가 3건이며, 그중 2건은 화요일 18시 KST 마감 후 문의다. 전체 고객의 문의 비율로 해석하지 않는다.[case-1][case-2][case-3][case-4][policy]
- 마감 전에는 앱의 구독 관리 경로를 안내하고, 마감 후 이번 회차 처리 여부는 운영자가 출고 상태를 확인한 뒤 안내한다. 변경·취소는 보장하지 않는다.[policy]
- 결제 문의는 주문 번호로 확인하고 카드 전체 번호는 요청하지 않는다. 아래 변경안은 제안이며, 적용 후에는 문의 기록과 이관 기록으로 안내 정확도와 반복 문의를 확인한다.[policy]

## 세부 항목

### 마감 전 변경 경로 안내

- **우선순위** 높음
- **문제** 마감 전 배송지 변경 메뉴를 찾는 문의가 있었다. 변경 완료 여부는 확인되지 않았다.[case-2]
- **근거** 화요일 17시 40분 KST 문의였으며, 정책상 화요일 18시 이전에는 앱의 구독 관리에서 해당 회차 배송지 변경 또는 건너뛰기가 가능하다.[case-2][policy]
- **변경** 제안: FAQ와 상담 안내문에 ‘앱 → 구독 관리’ 경로, 화요일 18시 KST 마감, 고객이 변경 완료 여부를 앱에서 확인해야 한다는 안내를 함께 둔다. 화면에서 메뉴가 보이지 않으면 발생 시각과 화면 상황만 확인해 운영팀에 이관한다.
- **담당 역할** 고객지원 리드: 안내문 정리. 앱 운영 담당: 실제 화면 경로 확인.
- **확인 방법** 앱 운영 담당이 현재 화면에서 경로와 표시 조건을 확인한 뒤 안내문과 대조한다. 적용 후 해당 유형 문의에서 안내 경로가 정확했는지 기록을 표본 점검한다.
- **완료 조건** 실제 화면과 일치하는 안내문이 확인되고, 마감 시각과 변경 완료 여부의 확인 필요성이 상담 문구에 포함된다.

### 마감 후 이번 회차 처리 이관

- **우선순위** 높음
- **문제** 마감 후 건너뛰기 또는 주소 변경의 이번 회차 반영 여부를 묻는 문의가 있었다. 두 건 모두 출고 상태가 제공되지 않았고, 주소 변경 건의 저장된 주소도 확인되지 않았다.[case-1][case-4]
- **근거** 수요일 건너뛰기 문의와 화요일 18시 20분 KST 주소 변경 문의가 있었다. 마감 후에는 운영자가 출고 상태를 확인하며 변경·취소를 보장하지 않는다.[case-1][case-4][policy]
- **변경** 제안: 상담 체크리스트에 회차, 요청 시각, 요청 종류, 앱에서 확인되는 내용만 기록하도록 하고 ‘이번 회차 반영 여부는 출고 상태 확인 후 안내’ 문구를 둔다. 버튼이 보이지 않은 원인은 추정하지 않는다. 출고 상태가 기록에 없거나 반영 여부가 불명확하면 운영 담당에게 이관한다.
- **담당 역할** 고객지원 리드: 체크리스트와 안내문. 출고 운영 담당: 출고 상태 확인 및 회신.
- **확인 방법** 적용 후 마감 후 문의의 이관 기록에서 출고 상태 확인 여부와 최종 안내 문구를 대조하고, 확인 전 반영·취소를 확답한 사례가 있는지 점검한다.
- **완료 조건** 마감 후 문의 이관에 필요한 최소 정보가 남고, 확인되지 않은 출고 상태나 이번 회차 반영 여부를 확답하지 않은 기록이 확인된다.

### 결제 내역 확인 절차

- **우선순위** 높음
- **문제** 결제가 두 건처럼 보인다는 문의가 있었다. 같은 주문인지 또는 승인·매입이 중복됐는지는 확인되지 않았다.[case-3]
- **근거** 정책상 결제 문의는 주문 번호로 확인하며 카드 전체 번호는 받지 않는다.[policy]
- **변경** 제안: 상담원이 주문 번호와 고객이 본 결제 내역의 표시 시점·금액을 확인해 결제 담당에게 넘기는 절차를 둔다. 중복 결제 또는 환불 가능 여부는 확인 전 단정하지 않고, 카드 전체 번호는 요청하지 않는다.
- **담당 역할** 고객지원 리드: 확인 항목과 문구. 결제 담당: 주문·결제 내역 대조.
- **확인 방법** 적용 후 결제 문의 이관 기록을 점검해 주문 번호가 확인에 쓰였는지, 카드 전체 번호 요청이나 확인 전 중복 결제·환불 확답이 없었는지 확인한다.
- **완료 조건** 결제 담당이 확인에 필요한 주문 번호를 전달받고, 고객 안내가 확인된 내역의 범위를 넘지 않는다.

### 반복 문의 지표와 예외 점검

- **우선순위** 중간
- **문제** 현재 자료는 문의 4건의 사례로, 전체 고객의 문의율이나 원인을 판단할 분모가 없다.[case-1][case-2][case-3][case-4]
- **근거** 4건 중 배송 일정·변경 문의는 3건, 결제 내역 문의는 1건이다. 배송 관련 3건 중 2건이 마감 후 문의다.[case-1][case-2][case-3][case-4][policy]
- **변경** 제안: 적용 전후 같은 기간·채널의 전체 접수 문의 건수를 분모로 삼아 배송 일정·변경 문의, 마감 후 이번 회차 문의, 결제 내역 문의의 건수와 비율을 비교한다. 동일 문의의 재접수는 별도 표시하고, 화면 경로 불일치·출고 상태 미확인·결제 내역 미확인 사례는 예외로 집계해 담당자에게 이관한다.
- **담당 역할** 고객지원 운영 담당: 문의 분류·집계. 앱·출고·결제 담당: 각 예외 확인.
- **확인 방법** 집계 기간, 채널, 전체 접수 건수, 분류 기준을 함께 기록하고 적용 전후 동일 기준으로 비교한다. 예외 건은 담당자 회신과 고객 안내가 연결됐는지 확인한다.
- **완료 조건** 분모와 분류 기준이 명시된 전후 비교표가 작성되고, 예외 건의 이관 및 회신 누락 여부를 점검할 수 있다.
