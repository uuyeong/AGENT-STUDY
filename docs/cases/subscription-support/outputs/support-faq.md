# 정기배송 문의 분류·FAQ 및 답장 초안

확인된 운영 기준: 정기배송은 목요일에 발송한다. KST 화요일 18시 이전에는 앱 ‘구독 관리’에서 해당 회차 건너뛰기 또는 배송지 변경이 가능하다. 마감 후에는 운영자가 출고 상태를 확인하며, 변경·취소를 보장하지 않는다. 결제 문의는 주문 번호로 확인하고 카드 전체 번호는 받지 않는다. [policy]

상담원용 FAQ
Q. 이번 회차를 건너뛰려면 어떻게 하나요? A. KST 화요일 18시 이전에 앱 ‘구독 관리’에서 해당 회차를 건너뛸 수 있습니다. 마감 후에는 운영자가 출고 상태를 확인하며 변경·취소를 보장하지 않습니다. [policy]
Q. 배송지는 어디서 바꾸고, 이번 회차에 반영되나요? A. KST 화요일 18시 이전에 앱 ‘구독 관리’에서 변경할 수 있습니다. 마감 후 변경의 이번 회차 반영 여부는 출고 상태 확인이 필요하며 보장할 수 없습니다. [policy]
Q. 결제가 중복된 것 같으면 어떻게 확인하나요? A. 주문 번호로 결제 내역을 확인합니다. 카드 전체 번호는 요청하거나 받지 않습니다. 중복 여부나 환불 가능 여부는 확인 전 확답하지 않습니다. [policy]

1. 건너뛰기 문의 [case-1]

답장 초안:
고객님, 이번 회차 건너뛰기 버튼이 보이지 않아 문의 주셨군요. 건너뛰기는 KST 화요일 18시 이전에 앱 ‘구독 관리’에서 가능합니다. 현재는 마감 후이므로 출고 상태를 확인한 뒤 가능 여부를 안내드리겠습니다. 변경·취소를 보장해 드리기 어려운 점 양해 부탁드립니다. [case-1][policy]

운영팀 이관: 이번 회차 건너뛰기를 계속 요청하면 출고 상태와 처리 가능 여부 확인을 요청한다. 버튼이 보이지 않는 현상이 계속되면 사용 환경과 화면을 확인해 오류 신고 여부를 판단한다. 버튼 미표시의 원인은 아직 확인되지 않았다. [case-1][policy] (이관 기준: 운영 제안)

2. 배송지 변경 메뉴 문의 [case-2]

답장 초안:
고객님, 배송지는 KST 화요일 18시 이전에 앱 ‘구독 관리’에서 변경하실 수 있습니다. 변경 후 이번 회차에 적용할 주소가 맞게 저장됐는지 확인해 주세요. [case-2][policy]

운영팀 이관: 고객이 메뉴에 접근하지 못하거나 마감 전 변경 완료 여부를 확인할 수 없다고 하면 신속히 확인을 요청한다. 문의 시각은 마감 전이지만 실제 변경 완료 여부는 확인되지 않았다. [case-2][policy] (이관 기준: 운영 제안)

4. 마감 후 배송지 변경 문의 [case-4]

답장 초안:
고객님, 이번 회차 배송지 반영 여부를 확인해 보겠습니다. 배송지 변경 마감은 KST 화요일 18시이며, 마감 후에는 운영자가 출고 상태를 확인해야 합니다. 현재 이번 회차 반영을 확답드릴 수는 없습니다. [case-4][policy]

운영팀 이관: 저장된 주소와 출고 상태를 확인하고, 이번 회차 반영 가능 여부가 확인된 뒤 고객에게 안내한다. 고객이 변경했다고 말한 사실만으로 저장 또는 반영 완료로 판단하지 않는다. [case-4][policy] (이관 기준: 운영 제안)

3. 중복 결제 문의 [case-3]

답장 초안:
고객님, 결제가 두 건처럼 보여 문의 주셨군요. 확인을 위해 주문 번호를 알려주시겠어요? 카드 전체 번호는 보내지 않으셔도 됩니다. 결제 내역을 확인한 뒤 안내드리겠습니다. [case-3][policy]

운영팀 이관 및 사람 검토: 주문 번호로 내역을 대조해 동일 주문 여부와 각 결제의 승인·매입 상태를 확인한다. 중복 결제나 환불 가능 여부는 확인 전 판단하지 않는다. 결제 문의 답장 발송에는 사람 승인이 필요하다. [case-3][policy] (확인·이관 절차: 운영 제안)
