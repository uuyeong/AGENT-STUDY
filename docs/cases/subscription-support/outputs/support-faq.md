# 정기배송 문의 분류·답장 초안

## 핵심 요약

- 4건 중 배송 일정·변경 문의는 3건, 결제 내역 문의는 1건이다. 배송 관련 3건 중 2건은 화요일 18시 KST 마감 후 문의다.[case-1][case-2][case-3][case-4][policy]
- 마감 후 건너뛰기·주소 변경의 이번 회차 처리 여부는 출고 상태 확인 뒤 안내하고, 중복 결제 여부는 주문 번호로 확인한다. 변경·취소나 환불을 확답하지 않고 카드 전체 번호는 요청하지 않는다.[policy][case-1][case-3][case-4]

## 고객 답장 초안

1. [고객 성함]님, 이번 주 배송 건너뛰기 문의를 확인했습니다. 건너뛰기는 화요일 18시 KST 이전에 앱의 구독 관리에서 가능합니다.[policy] 수요일에 버튼이 보이지 않는 상황과 이번 회차의 출고 상태를 운영팀에 확인한 뒤 안내드리겠습니다.[case-1][policy]

2. [고객 성함]님, 배송지는 앱의 구독 관리에서 변경하실 수 있습니다. 이번 회차 변경 마감은 화요일 18시 KST입니다.[policy] 변경 후 저장 여부를 확인해 주세요. 메뉴가 보이지 않거나 저장이 되지 않으면 알려주시면 확인하겠습니다.

3. [고객 성함]님, 결제가 두 건처럼 보이는 내역을 확인하겠습니다.[case-3] 해당 주문 번호와 결제 내역에 표시된 날짜·금액을 알려주세요. 카드 전체 번호는 보내지 않으셔도 됩니다.[policy] 확인 후 안내드리겠습니다.

4. [고객 성함]님, 주소를 변경하셨더라도 이번 회차 반영 마감인 화요일 18시 KST 이후의 변경은 반영을 보장할 수 없습니다.[case-4][policy] 저장된 주소와 출고 상태를 확인한 뒤 이번 회차 적용 여부를 안내드리겠습니다.[case-4][policy]

## 상담원 확인·운영팀 이관

- 1번: 주문 번호와 대상 회차를 확인하고, 버튼이 보이지 않는 화면·시점을 확인한다. 마감 후 문의이므로 운영팀에 출고 상태와 이번 회차 건너뛰기 처리 가능 여부를 조회 요청한다. 출고 여부는 현재 기록에 없다.[case-1][policy]
- 2번: 고객에게 앱 구독 관리 경로를 안내하고 변경 저장 여부를 확인한다.[policy][case-2] 메뉴가 없거나 저장되지 않는다고 하면 화면·발생 시점을 받아 운영팀에 확인 요청한다. 17:40 KST 문의이므로 18시 마감 전 안내를 우선한다.[case-2][policy]
- 3번: 주문 번호로 두 내역이 같은 주문에 해당하는지, 승인·매입이 실제로 중복됐는지 결제 담당자에게 확인 요청한다. 현재 자료만으로 중복 결제나 환불 가능 여부를 판단하지 않는다.[case-3][policy]
- 4번: 주문 번호와 대상 회차를 확인하고 운영팀에 저장된 주소 및 출고 상태 조회를 요청한다. 조회 결과 전에는 이번 회차 반영·취소 가능 여부를 확답하지 않는다.[case-4][policy]

공통으로 카드 전체 번호는 요청하거나 수집하지 않는다.[policy] 고객 이름, 주문 번호, 대상 회차처럼 처리에 필요한 최소 정보만 확인한다. 현재 제공된 근거는 운영 정책이며 별도 FAQ 문서는 제공되지 않았다.[policy] 운영팀 조회 결과가 필요한 항목은 결과를 확인한 뒤 최종 안내 문구를 결정한다.
