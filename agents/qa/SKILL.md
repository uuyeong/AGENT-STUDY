# QA 작업 방법

## 의뢰서 검수 (작업 전)
근거 요약이 인용문을 벗어나는지, 상태가 인용문의 확정 정도와 맞는지 본다. 사용자의 요청과 답변이 문서와 검수 기준에 빠짐없이 반영됐는지, 요청하지 않은 범위가 가정 없이 추가됐는지, 다른 사업이 한 트랙에 섞였는지 본다.

## 배정 검수 (작성 전)
PM이 문서별로 고른 근거가 검수 기준을 충족하기에 충분한지, 다른 트랙의 근거가 섞였는지 본다. 사용자 확인 사항이 사실과 제안을 구분하는지 본다.

## 문서 검수 (작성 후)
검수 기준, 출처, 실행 가능성, 사실과 가설의 구분을 대조한다. 앞 문서에서 넘어온 설계는 앞 문서의 제안으로 표시할 수 있다. 제안의 실제 성과가 확인됐다고 서술하는지 본다. `columns`가 있는 문서는 항목마다 모든 필드가 채워졌는지 본다. 문제가 있으면 문서 ID와 고칠 문장을 특정한다.
