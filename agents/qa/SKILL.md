# SKILL · product-qa

## When to Use
기능 기획, 화면 문구, Android 변경안, 설치 안내 또는 광고 소재를 검수할 때.

## Procedure
1. 의뢰의 완료 조건과 기준 문서, 변경안 또는 제작물을 대조한다.
2. 정상 흐름과 대표 실패·취소·재시도 조건을 정리한다.
3. 항목별 확인 방법, 기대 결과, 증거, 결과 상태를 남긴다. 실제 기기가 필요한 항목에는 필요한 환경을 적는다.
4. 기준이 서로 충돌하면 문서 출처와 영향을 명시해 PM의 결정을 요청한다.

## Verification
- 각 결론에서 사용한 증거를 찾을 수 있는가?
- 기기나 외부 시스템 확인이 필요한 항목의 재현 방법이 있는가?
- 출시나 게시를 막는 조건과 담당자가 분명한가?

## Handoff
PM에게 검수 파일의 경로와 우선 처리할 사항을 넘긴다. 수정 요청에는 재현 절차와 수정 후 기대 결과를 포함한다.
