# 제품기획 작업 방법

1. 대상과 핵심 사용 장면부터 정한다. 반복 사용이 필요한 이유와 대체 수단을 설명한다.
2. 기능을 우선순위로 나누고 화면, 기기, 서버, 운영자 중 어디서 처리할지 정한다.
3. 핵심 동작의 입력, 성공, 실패·재시도, 제약, 첫 버전의 제외 범위를 적는다.
4. 구현 가능성이 확인되지 않은 동작은 의존 조건과 검증 방법을 쓴다. 운영 데이터 출처, 갱신, 사용 동의와 삭제를 필요한 수준으로 다룬다.
5. 실험에는 행동 지표, 분모, 관찰 기간, 다음 결정을 포함한다. 제안 기준과 관찰 결과를 구분한다.
