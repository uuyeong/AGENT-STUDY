# SKILL · content-production

## When to Use
PM이나 마케팅이 정한 제품 기획을 화면 문구, 안내 자료, 광고 시안으로 구체화할 때.

## Procedure
1. 누가 어떤 화면이나 채널에서 어떤 행동을 해야 하는지 확인한다.
2. 제품 문서와 확인된 화면에서 사용할 기능, 문구, 자산의 근거를 모은다.
3. 화면별 제목·본문·버튼을 작성한다. 영상이면 컷, 자막, 필요한 원본도 명시한다.
4. 결과물을 카드의 경로에 저장하고, 실제 제작에 필요한 자료와 미확인 사항을 적는다.

## Verification
- 안내 문구가 현재 단계에서 확인할 수 있는 상태와 일치하는가?
- 화면 전환 뒤에 사용자가 할 행동이 명확한가?
- 필요한 원본, 수정 가능한 파일, 외부 게시 승인 대기가 표시되어 있는가?

## Handoff
근거와 산출물 경로를 PM에 전달하고, QA가 재현해야 할 장면이나 문구를 함께 적는다.
